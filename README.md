# บทที่ 3: เอนไซม์ Big 5 — ผู้พิทักษ์ตับที่คุณต้องรู้จัก

## 📌 บทนำ: โรงงานกำจัดสารแปลกปลอมในร่างกาย

> "ลองนึกภาพว่าตับของคุณคือโรงงานกำจัดสารแปลกปลอมขนาดใหญ่ที่ไม่เคยหยุดทำงาน ทุกครั้งที่คุณกลืนยาเม็ดลงไป โรงงานนั้นจะส่งสัญญาณเรียกเครื่องจักรหลายสายพานทำงานพร้อมกัน แต่เครื่องจักรของแต่ละคนไม่เหมือนกัน บางตัวแข็งแกร่ง บางตัวอ่อนแอ บางตัวแทบไม่ทำงานเลย และทั้งหมดนั้นถูกกำหนดโดยรหัส DNA ของคุณตั้งแต่วันที่ปฏิสนธิ"

ในบทที่ 1 เราได้เรียนรู้เกี่ยวกับการถ่ายทอดข้อมูลจากดีเอ็นเอ (DNA) ไปสู่โปรตีน และในบทที่ 2 เราได้ทำความเข้าใจระบบการจัดการยาของร่างกายผ่านกระบวนการ ADME เป็นที่เรียบร้อยแล้ว สำหรับในบทนี้ จะเป็นการนำองค์ความรู้ทั้งสองส่วนมาบรรจบกันในจุดที่สำคัญที่สุดทางคลินิก นั่นคือการทำความรู้จักกับ **เอนไซม์กลุ่ม "Big 5"** ซึ่งเป็นกลุ่มเอนไซม์หลักที่รับผิดชอบการย่อยสลายยากว่า 70% ของยาทั้งหมดที่ใช้ในทางการแพทย์

## 3.1 ทำไมต้องรู้จัก Big 5?

แม้ว่าเอนไซม์กลุ่ม **CYP450 (Cytochrome P450)** จะมีมากกว่า 50 ชนิดในร่างกายมนุษย์ แต่ในทางปฏิบัติทางคลินิก มีเพียง 5 ตัวนี้เท่านั้นที่มีบทบาทสำคัญและมีความแปรปรวนสูงพอที่จะเปลี่ยนแปลงผลการรักษาได้อย่างมีนัยสำคัญ

### ตารางที่ 3.1: สรุปภาพรวมและลักษณะเฉพาะของเอนไซม์กลุ่ม Big 5

| เอนไซม์ | % ยาที่ย่อย | ตำแหน่งโครโมโซม | ลักษณะเด่นและบทบาททางคลินิก |
| :--- | :---: | :---: | :--- |
| **CYP2D6** | ~25% | 22q13 | มี Star Alleles > 100 ชนิด, ถูกยับยั้ง (Inhibit) ได้ง่ายมาก |
| **CYP2C19** | ~15% | 10q24 | อัตราผู้ป่วยกลุ่ม PM สูงในชาวเอเชีย, สัมพันธ์โดยตรงกับยา Clopidogrel |
| **CYP2C9** | ~15% | 10q24 | ย่อยยากลุ่ม Narrow Therapeutic Index เช่น Warfarin |
| **CYP3A4** | ~45% | 7q22 | เป็นเอนไซม์ที่พบปริมาณมากที่สุดในตับ, มีปฏิกิริยาระหว่างยา (DDI) สูง |
| **CYP3A5** | ~8% | 7q22 | มีความแตกต่างระหว่างเชื้อชาติสูงมาก, สัมพันธ์กับยา Tacrolimus |

## 3.2 Inhibitor และ Inducer: ยาที่ "ปิด" และ "เร่ง" เอนไซม์

ก่อนที่จะลงลึกในรายละเอียดของเอนไซม์แต่ละตัว สิ่งจำเป็นอันดับแรกคือการทำความเข้าใจกลไกพื้นฐาน 2 รูปแบบที่ส่งผลกระทบต่อการทำงานของเอนไซม์:

### 3.2.1 Inhibitor (ตัวยับยั้งเอนไซม์) — ยาที่ "ปิด" โรงงาน
**Inhibitor** คือยาหรือสารเคมีที่เข้าไปจับกับเอนไซม์แล้วขัดขวางกลไกการทำงาน ส่งผลให้เอนไซม์ตัวนั้นย่อยสลายยาอื่น (Substrate) ได้ลดลง ทำให้ระดับยา Substrate สะสมในกระแสเลือดสูงขึ้นจนอาจเกิดอันตรายหรือพิษจากยาได้

* **กรณีศึกษาที่สำคัญ:**
    * $\text{Fluoxetine} \rightarrow \text{ยับยั้ง CYP2D6} \rightarrow \text{Metoprolol สะสมเกินขนาด} \rightarrow$ ส่งผลให้ความดันโลหิตต่ำและหัวใจเต้นช้าผิดปกติ
    * $\text{Clarithromycin} \rightarrow \text{ยับยั้ง CYP3A4} \rightarrow \text{Simvastatin สะสมในเลือด} \rightarrow$ เพิ่มความเสี่ยงต่อการเกิดโรคกล้ามเนื้อสลาย (Myopathy)

### 3.2.2 Inducer (ตัวกระตุ้นเอนไซม์) — ยาที่ "เร่ง" สายพาน
**Inducer** คือยาหรือสารที่กระตุ้นให้เซลล์ตับสังเคราะห์เอนไซม์ขึ้นมามากกว่าปกติ ส่งผลให้ยา Substrate ถูกกำจัดออกจากร่างกายอย่างรวดเร็ว ทำให้ระดับยาในกระแสเลือดลดต่ำลงจนอาจไม่เกิดผลการรักษา

* **กรณีศึกษาที่สำคัญ:**
    * $\text{Rifampicin} \rightarrow \text{กระตุ้น CYP3A4} \rightarrow \text{Tacrolimus ถูกกำจัดเร็วเกินไป} \rightarrow$ แพทย์จำเป็นต้องเพิ่มขนาดยาขึ้น 3–5 เท่าเพื่อให้คงผลการรักษา
    * $\text{St. John's Wort (สมุนไพร)} \rightarrow \text{กระตุ้น CYP3A4} \rightarrow \text{ยาคุมกำเนิดถูกทำลายเร็ว} \rightarrow$ ส่งผลให้ประสิทธิภาพการคุมกำเนิดล้มเหลวและอาจตั้งครรภ์ได้

### 3.2.3 Phenoconversion: เมื่อยาเปลี่ยนฟีโนไทป์ชั่วคราว
แนวคิดหลักที่มีความสำคัญอย่างยิ่งยวดในปัจจุบันคือ **Phenoconversion** หมายถึง ภาวะที่ผู้ป่วยมีผลตรวจทางพันธุกรรมเป็นกลุ่มย่อยยาปกติ (*Normal Metabolizer; NM*) แต่เมื่อได้รับยาที่เป็น Inhibitor ร่วมด้วย ร่างกายจะแสดงพฤติกรรมเสมือนเป็นกลุ่มย่อยยาบกพร่อง (*Poor Metabolizer; PM*) ชั่วคราว ตราบเท่าที่ยานั้นยังไม่ถูกขับออกหมด

> 💡 **นัยสำคัญทางคลินิก:** แม้ผลการตรวจยีนจะระบุว่าคุณเป็นกลุ่ม NM แต่ถ้าคุณรับประทานยา Fluoxetine ร่วมกับ Codeine ร่างกายของคุณจะเปลี่ยนสภาพเป็น PM ชั่วคราว (ทำให้ยาแก้ปวดไม่ได้ผล) ดังนั้น การดูผลตรวจยีนเพียงอย่างเดียวจึงไม่เพียงพอ แพทย์จำเป็นต้องประเมินรายการยาทั้งหมดที่ผู้ป่วยได้รับร่วมด้วยเสมอ

## 3.3 CYP2D6 — นักสู้อเนกประสงค์

### 3.3.1 ภาพรวม
**CYP2D6** เป็นเอนไซม์ที่มีความแปรปรวนทางพันธุกรรมสูงที่สุดในบรรดา Big 5 โดยปัจจุบันมีการค้นพบ *Star Alleles* มากกว่า 100 ชนิด และมีหน้าที่ย่อยสลายยากว่า 25% ในท้องตลาด แม้ว่าตัวโปรตีน CYP2D6 จะคิดเป็นเพียง 1–4% ของเอนไซม์ CYP450 ทั้งหมดในตับ แต่เนื่องจากมีค่าความจำเพาะสูง (High Affinity) จึงสามารถทำหน้าที่ย่อยสลายยาในปริมาณมากได้อย่างมีประสิทธิภาพ [^1]

### 3.3.2 Star Alleles สำคัญในประชากรไทย
โครงสร้างทางพันธุกรรมของ CYP2D6 ที่พบบ่อยในประชากรไทย ประกอบด้วย:

* **`*1`** : Normal function (Activity Score = 1.0) $\rightarrow$ ความถี่พบประมาณ 40–50%
* **`*2`** : Decreased function (Activity Score = 0.5) $\rightarrow$ ความถี่พบประมาณ 20–30%
* **`*4`** : No function (Activity Score = 0) $\rightarrow$ ความถี่พบประมาณ 1% *(พบได้น้อยมากในกลุ่มประชากรเอเชีย)*
* **`*10`** : Decreased function (Activity Score = 0.25) $\rightarrow$ ความถี่พบประมาณ 40% [^2] *(พบสูงมากในชาวเอเชีย)*
* **`*1xN`** : (Gene Duplication) Increased function (Activity Score $\ge$ 2.0) $\rightarrow$ ความถี่พบประมาณ 1–2%

> 📌 **ข้อสังเกตเชิงลึก:** เนื่องด้วยอัลลีล `CYP2D6*10` มีอัตราความถี่สูงมากในคนไทย (~40%) ส่งผลให้ประชากรไทยจำนวนมากถูกจัดอยู่ในกลุ่มย่อยยาได้ลดลงระดับปานกลาง (**Intermediate Metabolizer; IM**) โดยปริยาย แม้ว่าจะไม่ได้ตรวจพบอัลลีลชนิดที่หยุดทำงานโดยสมบูรณ์ก็ตาม

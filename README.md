# บทที่ 4: ดาวนำทาง Star Alleles และฟีโนไทป์

## วัตถุประสงค์การเรียนรู้

หลังจากอ่านบทนี้จบ ผู้อ่านจะสามารถ:
วัตถุประสงค์การเรียนรู้

หลังจากอ่านบทนี้จบ ผู้อ่านจะสามารถ:

1. อธิบายความหมายของ Star Allele และเหตุผลที่ใช้ในการจำแนกรูปแบบของยีน
2. อธิบายความสัมพันธ์ระหว่าง Star Allele, Diplotype, Activity Score และ Metabolizer Phenotype
3. จำแนกฟีโนไทป์การเผาผลาญยา ได้แก่ PM, IM, NM, RM และ UM จากตัวอย่างผลตรวจยีนที่กำหนดให้
4. วิเคราะห์ว่าฟีโนไทป์ที่แตกต่างกันส่งผลต่อการตอบสนองต่อยาอย่างไร โดยเฉพาะยาที่ออกฤทธิ์เอง (active drug) และ prodrug
5. อธิบายว่าเกณฑ์การแปลผลฟีโนไทป์เป็นแบบเฉพาะยีน (gene-specific) และไม่สามารถนำเกณฑ์ของยีนหนึ่งไปใช้กับอีกยีนหนึ่งโดยตรง

## Poor / Intermediate / Normal / Rapid / Ultrarapid Metabolizer

ในบทที่ 3 เราได้รู้จักกันแล้วว่า ร่างกายของเรามี "โรงงานสลายยา" อยู่ในตับ ซึ่งก็คือกลุ่มเอนไซม์ตระกูล CYP450 อย่าง CYP2D6, CYP2C19, CYP2C9, CYP3A4 และ CYP3A5

แต่โรงงานเดียวกันนี้ไม่ได้ทำงานเหมือนกันในทุกคน แล้วเราจะรู้ได้อย่างไรว่า "พนักงาน" แต่ละคนในโรงงานมีสมรรถนะการทำงานแบบไหน?

บทนี้เราจะมาทำความรู้จักกับ Star Alleles หรือ "รหัสประจำตัว" ของรูปแบบยีน ซึ่งจะช่วยให้เราเข้าใจว่า พนักงานแต่ละคนมีสมรรถนะในการทำงานอย่างไร ตั้งแต่ทำงานได้ตามปกติ ทำงานลดลง ไปจนถึงทำงานมากขึ้นหรือไม่สามารถทำงานได้เลย

นี่คือหน้าที่ของสิ่งที่เรียกว่า **Star Allele** ซึ่งเปรียบเสมือน "ดาวนำทาง" ที่จะพาเราไปสู่คำตอบว่า ยีนของเรารุ่นไหน ทำงานเก่งแค่ไหน และสุดท้ายแล้วร่างกายเราจะจัดการกับยาได้เร็วหรือช้าเพียงใด

***

## ตอนที่ 1: Star Allele คืออะไร (ฉบับเข้าใจง่าย)

### 1.1 ทำไมต้องมีเครื่องหมายดอกจัน (*)

นักวิทยาศาสตร์ตั้งชื่อ "รูปแบบ" ต่างๆ ของยีนแต่ละตัวด้วยเครื่องหมายดอกจัน (*) ตามด้วยตัวเลข ตามระบบการตั้งชื่อของ Pharmacogene Variation Consortium (PharmVar) [1] เช่น

- CYP2D6 **\*1**
- CYP2D6 **\*2**
- CYP2D6 **\*4**
- CYP2D6 **\*17**

เพื่อให้เข้าใจง่ายขึ้น ขอให้ผู้อ่านนึกภาพ **เอนไซม์แต่ละตัวในตับ เปรียบเสมือน "พนักงานที่ประจำอยู่ในสายการผลิตของโรงงาน"** โดยหน้าที่ของพนักงานคนนี้คือ รับ "ยา" ที่ส่งเข้ามาในสายพาน แล้วทำการ "แปรรูป" หรือ "สลาย" ให้กลายเป็นรูปแบบที่ร่างกายจะกำจัดออกไปได้ (หรือในบางกรณี คือแปรรูปให้ยากลายเป็นสารที่ออกฤทธิ์ได้จริง)

**Star Allele** คือ "รหัสประจำตัว" ที่บอกว่า พนักงานคนนี้ได้รับการฝึกฝนหรือมีศักยภาพในการทำงานแบบใด ซึ่งกำหนดมาตั้งแต่ระดับพันธุกรรม (DNA) ความแตกต่างเพียงเล็กน้อยในแบบแผนของ DNA (เรียกว่า variant หรือการกลายพันธุ์) จะส่งผลต่อ "สมรรถนะการทำงาน" ของพนักงานแต่ละคน ซึ่งแบ่งได้เป็น 4 ลักษณะหลัก ดังนี้ [2]

| ลักษณะการกลายพันธุ์ | ผลต่อสมรรถนะของเอนไซม์ | ตัวอย่าง Star Allele |
|---|---|---|
| ไม่มีผลกระทบต่อโครงสร้างเอนไซม์ | ทำงานได้ปกติ (Normal function) | \*1, \*2 |
| ทำให้โครงสร้างเอนไซม์เปลี่ยนแปลงบางส่วน | ทำงานได้ลดลง (Decreased function) | \*10 |
| ทำให้ไม่สามารถสร้างโปรตีนที่สมบูรณ์ได้เลย หรือยีนขาดหายไป | ไม่สามารถทำงานได้ (No function) | \*4, \*5 |
| มีจำนวนสำเนาของยีนเพิ่มขึ้นจากปกติ (Gene duplication) | ทำงานได้มากกว่าปกติ (Increased function) | \*1xN |

> **สรุป:** Star Allele คือรหัสที่ระบุว่า พนักงาน (เอนไซม์) แต่ละคนที่ได้รับมอบหมายให้ทำงานในสายการผลิตนั้น มีสมรรถนะการทำงานอยู่ในระดับใด — ทำงานได้เต็มที่ ทำงานได้เพียงบางส่วน ทำงานไม่ได้เลย หรือทำงานได้มากเกินกว่ามาตรฐาน

### 1.2 ตัวอย่าง Star Allele ที่พบบ่อย (ยกตัวอย่างจาก CYP2D6)

เอนไซม์ CYP2D6 เป็นตัวอย่างที่ดีที่สุดในการอธิบาย เพราะมี Star Allele หลากหลายและถูกศึกษามากที่สุดตัวหนึ่งในโลก [1,3]

| Star Allele | ความหมาย (ภาษาไม่ทางการ) | ระดับการทำงาน |
|---|---|---|
| **\*1** | รุ่นมาตรฐาน ไม่มีจุดบกพร่อง | ทำงานปกติ (Normal function) |
| **\*2** | มีจุดเปลี่ยนแปลงเล็กน้อย แต่ทำงานได้ปกติ | ทำงานปกติ (Normal function) |
| **\*4** | จุดบกพร่องที่ทำให้ตัดต่อโปรตีนผิดพลาด สร้างเอนไซม์ไม่ได้เลย | **ใช้งานไม่ได้ (No function)** — พบบ่อยที่สุดในคนผิวขาว |
| **\*5** | ยีนทั้งท่อนหายไปเลย (gene deletion) | **ใช้งานไม่ได้ (No function)** |
| **\*10** | พบบ่อยในคนเอเชีย ทำให้เอนไซม์เสถียรน้อยลง | ทำงานได้บ้าง (Decreased function) |
| **\*1xN** (เช่น \*1x2, \*1x3) | มียีน \*1 ซ้ำกันหลายชุดในโครโมโซมเดียว | **ทำงานมากกว่าปกติ (Increased function)** |

**ข้อสังเกตที่สำคัญ:** ตัวเลขหลังดอกจันไม่ได้เรียงจาก "แย่ไปดี" หรือ "ดีไปแย่" มันเป็นเพียง **ลำดับการค้นพบ** เท่านั้น ต้องดูตารางอ้างอิงเสมอว่าอัลลีลนั้นจัดอยู่ในกลุ่มทำงานแบบไหน [1]

**ข้อควรระวังเพิ่มเติม:** หมายเลขดาวเป็นเพียงรหัสภายในของแต่ละยีนเท่านั้น ไม่ใช่รหัสสากลที่เทียบข้ามยีนได้ ตัวอย่างเช่น CYP2D6\*17 และ CYP2C19\*17 เป็นอัลลีลคนละตัวกันโดยสิ้นเชิง มีที่มาและระดับการทำงานต่างกัน (จะได้เห็นตัวอย่าง CYP2C19\*17 ในตอนที่ 4) ดังนั้นห้ามนำหมายเลขดาวของยีนหนึ่งไปเทียบเคียงกับอีกยีนหนึ่งโดยตรง

## ตอนที่ 2: Diplotype คืออะไร

### 2.1 อัลลีลสองชุดจากพ่อและแม่

โดยทั่วไป มนุษย์ได้รับยีนแต่ละตำแหน่งมาจากพ่อและแม่อย่างละหนึ่งชุด จึงมีอัลลีลสองชุดเป็นพื้นฐาน (ยกเว้นยีนบนโครโมโซม Y) อย่างไรก็ตาม ยีนบางชนิด เช่น CYP2D6 สามารถพบการเพิ่มจำนวนสำเนาของยีน (gene duplication/multiplication) ได้ ซึ่งจะกล่าวถึงในรูปของ \*1xN ต่อไป

ดังนั้น เวลาบอกว่า "จีโนไทป์" ของ CYP2D6 ของใครสักคน เราจึงต้องเขียนเป็นคู่เสมอ เรียกว่า **Diplotype** เช่น

```
CYP2D6 *1/*4
```

อ่านว่า "ได้รับอัลลีล \*1 มาจากพ่อ (หรือแม่) หนึ่งชุด และได้รับอัลลีล \*4 มาอีกหนึ่งชุด"

หากใช้อุปมาสายการผลิตที่กล่าวมาข้างต้น Diplotype ก็คือ **การที่มีพนักงาน 2 คน ประจำอยู่ในสายการผลิตเดียวกัน** โดยพนักงานคนหนึ่งได้รับมอบหมายหน้าที่มาจากฝ่ายพ่อ และอีกคนหนึ่งมาจากฝ่ายแม่ พนักงานทั้งสองคนทำงานร่วมกัน สมรรถนะโดยรวมของสายการผลิตจึงขึ้นอยู่กับสมรรถนะของพนักงานทั้งคู่รวมกัน

ตัวอย่างเช่น หากพนักงานคนแรกมีสมรรถนะปกติ (\*1) แต่พนักงานคนที่สองไม่สามารถทำงานได้เลย (\*4) สายการผลิตโดยรวมก็จะทำงานได้เพียงบางส่วน เนื่องจากมีพนักงานที่ทำงานได้จริงเพียงคนเดียว

### 2.2 ตัวอย่าง Diplotype ที่พบได้

| Diplotype | ความหมาย |
|---|---|
| \*1/\*1 | ได้รับอัลลีลปกติจากทั้งพ่อและแม่ |
| \*1/\*4 | ได้รับอัลลีลปกติ 1 ชุด และอัลลีลที่ใช้งานไม่ได้ 1 ชุด |
| \*4/\*4 | ได้รับอัลลีลที่ใช้งานไม่ได้จากทั้งสองฝ่าย |
| \*1/\*1xN | ได้รับอัลลีลปกติ 1 ชุด และอัลลีลที่มีสำเนาซ้ำ (ทำงานเกินปกติ) อีก 1 ชุด |

***

## ตอนที่ 3: Activity Score — ตัวเลขที่แปลง Diplotype ให้เป็นภาษาที่แพทย์ใช้ได้จริง

### 3.1 Activity Score: ตัวอย่างการแปลงค่า Diplotype ของ CYP2D6

> **หมายเหตุ:** Activity Score เป็นระบบที่ใช้ในการประเมินการทำงานของยีนบางชนิด โดยเฉพาะ CYP2D6 การกำหนดค่าและเกณฑ์แบ่งฟีโนไทป์อาจแตกต่างกันตามยีนและแนวทางขององค์กร ดังนั้นไม่ควรนำตาราง Activity Score ของ CYP2D6 ไปใช้กับยีนอื่นโดยตรง [3]

ตามอุปมาข้างต้น หากเปรียบแต่ละ Star Allele เหมือนพนักงานหนึ่งคนในสายการผลิต สำหรับ **CYP2D6** เราสามารถกำหนด **"คะแนนสมรรถนะการทำงาน" (Activity Value)** ให้กับพนักงานแต่ละคนได้ ตัวอย่างเช่น

| ระดับการทำงานของอัลลีล | ตัวอย่าง Activity Value ของ CYP2D6 |
|---|---|
| ใช้งานไม่ได้เลย (No function) เช่น \*4, \*5 | 0 |
| ทำงานได้บ้าง (Decreased function) เช่น \*10 | 0.25 – 0.5 |
| ทำงานปกติ (Normal function) เช่น \*1, \*2 | 1.0 |
| ทำงานเกินปกติ (Increased function) เช่น \*1xN | 1.0 ต่อสำเนา (เช่น \*1x2 = 2.0) |

> **หมายเหตุ:** Activity Value ของแต่ละ star allele ให้ยึดตามตาราง CYP2D6 ของ CPIC/PharmGKB ที่เป็นปัจจุบัน เนื่องจากการกำหนดค่าอาจมีการปรับปรุงตามหลักฐานใหม่ [3]

**Activity Score (AS)** ของคนคนหนึ่ง (สำหรับ CYP2D6) = คะแนนของอัลลีลตัวที่ 1 **บวก** คะแนนของอัลลีลตัวที่ 2

### 3.2 ตัวอย่างการคำนวณ

**ตัวอย่างที่ 1:** Diplotype = \*1/\*1
```
คะแนนอัลลีลที่ 1 (*1) = 1.0
คะแนนอัลลีลที่ 2 (*1) = 1.0
รวม Activity Score = 2.0
```

**ตัวอย่างที่ 2:** Diplotype = \*1/\*4
```
คะแนนอัลลีลที่ 1 (*1) = 1.0
คะแนนอัลลีลที่ 2 (*4) = 0
รวม Activity Score = 1.0
```

**ตัวอย่างที่ 3:** Diplotype = \*4/\*4
```
คะแนนอัลลีลที่ 1 (*4) = 0
คะแนนอัลลีลที่ 2 (*4) = 0
รวม Activity Score = 0
```

**ตัวอย่างที่ 4:** Diplotype = \*1/\*1x2 (มีสำเนาซ้ำ)
```
คะแนนอัลลีลที่ 1 (*1)   = 1.0
คะแนนอัลลีลที่ 2 (*1x2) = 2.0
รวม Activity Score = 3.0
```

## ตอนที่ 4: การจัดกลุ่มฟีโนไทป์การเผาผลาญยา

เมื่อได้ Activity Score แล้ว ขั้นตอนสุดท้ายคือนำคะแนนนั้นไปเทียบกับตารางเพื่อจัดกลุ่ม **ฟีโนไทป์การเผาผลาญยา (Metabolizer Phenotype)** ตามอุปมาสายการผลิตที่ใช้มาตลอดบทนี้ ยาที่รับประทานเข้าไปเปรียบเสมือนวัตถุดิบที่ถูกส่งเข้าสู่สายการผลิต โดยมีพนักงาน (เอนไซม์ที่กำหนดโดย Diplotype) เป็นผู้ดำเนินการแปรรูป ความเร็วของสายการผลิตโดยรวมจึงขึ้นอยู่กับสมรรถนะของพนักงานทั้งสองคนที่ประจำอยู่ ณ ตำแหน่งนั้น

### 4.1 ตัวอย่างการจัดฟีโนไทป์ของ CYP2D6

| ฟีโนไทป์ | CYP2D6 Activity Score |
|---|---|
| Poor Metabolizer (PM) | 0 |
| Intermediate Metabolizer (IM) | >0 ถึง <1.25 |
| Normal Metabolizer (NM) | 1.25 – 2.25 |
| Ultrarapid Metabolizer (UM) | >2.25 |

นอกจากนี้ยังมีกลุ่ม **Indeterminate** สำหรับกรณีที่ผลตรวจพบอัลลีลที่ยังไม่ทราบระดับการทำงานแน่ชัด (uncertain function allele) [3]

> **แล้ว Rapid Metabolizer อยู่ตรงไหน?**
> Rapid Metabolizer (RM) เป็นฟีโนไทป์ที่พบในบางยีนเท่านั้น ไม่ใช่ทุกยีนจะมีกลุ่มนี้ ตัวอย่างที่ชัดเจนคือ **CYP2C19** ซึ่งใช้การจับคู่ allele function เป็นหลักแทนการคำนวณ Activity Score แบบ CYP2D6 — CPIC กำหนดว่า Diplotype \*1/\*17 จัดเป็น Rapid Metabolizer ในขณะที่ \*17/\*17 จัดเป็น Ultrarapid Metabolizer [6,7] จะเห็นได้ว่าเกณฑ์การจัดกลุ่มฟีโนไทป์นั้นเป็นแบบเฉพาะยีน (gene-specific) ไม่ใช่สูตรสำเร็จเดียวที่ใช้ได้กับทุกยีน

### 4.2 อธิบายแต่ละฟีโนไทป์แบบง่ายๆ

**Poor Metabolizer (PM) — พนักงานทั้งสองคนไม่สามารถทำงานได้เลย**

คนกลุ่มนี้มีอัลลีลที่ใช้งานไม่ได้ทั้งสองข้าง (เช่น \*4/\*4) ร่างกายแทบไม่สามารถสลายยาบางชนิดได้เลย

- ถ้ายาตัวนั้นเป็น "ยาต้นฉบับที่ออกฤทธิ์เอง" → ยาจะค้างอยู่ในเลือดนาน เสี่ยงพิษ/ผลข้างเคียงสูง
- ถ้ายาตัวนั้นต้อง "ถูกเปลี่ยนรูปก่อนจึงจะออกฤทธิ์" (prodrug) → ยาจะไม่ได้ผล เพราะไม่ถูกเปลี่ยนเป็นสารออกฤทธิ์

**Intermediate Metabolizer (IM) — พนักงานคนหนึ่งทำงานปกติ อีกคนทำงานได้เพียงบางส่วน**

มีอัลลีลปกติ 1 ข้าง และอัลลีลที่ทำงานได้บ้าง/ไม่ได้เลยอีก 1 ข้าง (เช่น \*1/\*4 หรือ \*1/\*10) ร่างกายสลายยาได้ แต่ช้ากว่าคนทั่วไป

**Normal Metabolizer (NM) — พนักงานทั้งสองคนทำงานได้ตามมาตรฐาน**

มีอัลลีลปกติทั้งสองข้าง (เช่น \*1/\*1 หรือ \*1/\*2) นี่คือกลุ่มส่วนใหญ่ในประชากร

**Rapid Metabolizer (RM) — พนักงานทำงานได้เร็วกว่ามาตรฐานเล็กน้อย**

พบในบางยีนเท่านั้น เช่น CYP2C19\*1/\*17 ร่างกายสลายยาได้เร็วกว่าค่าเฉลี่ย แต่ยังไม่ถึงขั้นสุดโต่ง

**Ultrarapid Metabolizer (UM) — มีพนักงานเพิ่มจำนวนขึ้นจากปกติ หรือทำงานเร็วผิดปกติ**

เกิดได้จากสำเนายีนซ้ำ (เช่น CYP2D6\*1xN) หรือจากอัลลีลที่มีฟังก์ชันเพิ่มขึ้น (เช่น CYP2C19\*17/\*17)

- ถ้ายาตัวนั้นออกฤทธิ์เอง → ยาจะถูกกำจัดออกเร็วเกินไป จนได้ผลไม่เต็มที่
- ถ้ายาตัวนั้นเป็น prodrug → ยาจะถูกเปลี่ยนเป็นสารออกฤทธิ์เร็วและมากเกินไป เสี่ยงเกิดพิษ

***

## ตอนที่ 5: เคสผู้ป่วยจำลอง (เพื่อความเข้าใจ)

> **หมายเหตุสำคัญ:** เคสทั้งหมดต่อไปนี้เป็น **เคสสมมติที่สร้างขึ้นเพื่อการศึกษาเท่านั้น** ไม่ใช่คำแนะนำทางการแพทย์ หากท่านมีคำถามเกี่ยวกับยาที่ใช้อยู่ กรุณาปรึกษาแพทย์หรือเภสัชกร

### เคสที่ 1: คุณสมชาย — "กินยาแก้ปวดโคดีนแล้วไม่หายปวดเลย"

**ข้อมูล:** คุณสมชาย อายุ 45 ปี ผ่าตัดฟันคุด หมอให้ยาโคดีน (Codeine) กินแก้ปวด แต่กินไปแล้วไม่รู้สึกหายปวดเลยแม้แต่น้อย

**ผลตรวจยีน:** CYP2D6 **\*4/\*4**

**คำอธิบาย:**

โคดีนเป็นยาที่ตัวมันเองแทบไม่ออกฤทธิ์แก้ปวด แต่ร่างกายต้องใช้เอนไซม์ CYP2D6 "แปลงร่าง" โคดีนให้กลายเป็นมอร์ฟีน (morphine) ซึ่งเป็นสารที่ออกฤทธิ์แก้ปวดจริงๆ [4]

คุณสมชายมี Diplotype \*4/\*4 ซึ่งจัดเป็น Activity Score = 0 → ฟีโนไทป์ **Poor Metabolizer (PM)**

เนื่องจากคุณสมชายแทบไม่มีเอนไซม์ CYP2D6 ที่ใช้งานได้เลย จึงสามารถสร้าง morphine จาก codeine ได้น้อยมาก ส่งผลให้ฤทธิ์ระงับปวดจาก codeine อาจลดลงอย่างมาก

*แนวทางที่เหมาะสม:* แพทย์ควรพิจารณายาแก้ปวดกลุ่มอื่นที่ไม่ต้องพึ่งพา CYP2D6 ในการออกฤทธิ์ [4]

***

### เคสที่ 2: คุณวารี — "แม่ให้นมลูกแล้วลูกซึมผิดปกติ"

**ข้อมูล:** คุณวารีเพิ่งคลอดบุตร แพทย์ให้ยาโคดีนแก้ปวดหลังคลอด ไม่กี่วันต่อมาลูกน้อยที่กินนมแม่มีอาการซึมมาก ไม่ยอมดูดนม

**ผลตรวจยีน (สมมติ):** CYP2D6 **\*1/\*1xN** (มีสำเนายีนซ้ำ)

**คำอธิบาย:**

คุณวารีมี diplotype CYP2D6 \*1/\*1xN ซึ่งเป็นตัวอย่างของ genotype ที่สัมพันธ์กับ Ultrarapid Metabolizer (UM) ตามเกณฑ์ CYP2D6 ของ CPIC [3]

เนื่องจากร่างกายของคุณวารีเปลี่ยนโคดีนให้เป็นมอร์ฟีนได้ **เร็วและมากกว่าคนทั่วไป** ทำให้ระดับมอร์ฟีนในเลือดและในน้ำนมสูงกว่าปกติ เมื่อลูกดูดนมแม่เข้าไปจึงได้รับมอร์ฟีนในปริมาณที่มากเกินไปสำหรับทารก ทำให้เกิดอาการซึมได้

*เคสสมมตินี้สร้างขึ้นโดยอ้างอิงหลักการจากรายงานผู้ป่วยจริงที่มีการตีพิมพ์* ซึ่งพบว่าทารกเสียชีวิตจากพิษของมอร์ฟีนที่ได้รับผ่านน้ำนมแม่ที่เป็น CYP2D6 ultrarapid metabolizer และรับประทานโคดีน [5] นี่คือเหตุผลสำคัญที่ในปัจจุบันมีคำเตือนไม่ให้ใช้ยาโคดีนในมารดาที่ให้นมบุตร

***

### เคสที่ 3: คุณประไพ — "กินยาโคลพิโดเกรลป้องกันเส้นเลือดอุดตัน แต่ยังเกิดซ้ำ"

**ข้อมูล:** คุณประไพ อายุ 68 ปี เพิ่งใส่ขดลวดหัวใจ (stent) แพทย์ให้ยาโคลพิโดเกรล (Clopidogrel) เพื่อป้องกันลิ่มเลือดอุดตัน แต่ 3 เดือนต่อมากลับเกิดลิ่มเลือดอุดตันซ้ำ

**ผลตรวจยีน:** CYP2C19 **\*2/\*2**

**คำอธิบาย:**

โคลพิโดเกรลก็เป็นยาอีกชนิดที่ต้องถูก "แปลงร่าง" โดยเอนไซม์ CYP2C19 ก่อนจึงจะออกฤทธิ์ต้านการแข็งตัวของเลือดได้จริง [6]

คุณประไพมี Diplotype \*2/\*2 ซึ่งอัลลีล \*2 จัดเป็นชนิดใช้งานไม่ได้ (No function) ทำให้จัดเป็นฟีโนไทป์ **Poor Metabolizer (PM)**

การเปลี่ยน clopidogrel ไปเป็น active metabolite ในร่างกายของคุณประไพอาจลดลง ส่งผลให้ประสิทธิผลของยาในการยับยั้งเกล็ดเลือดลดลง และเพิ่มความเสี่ยงต่อเหตุการณ์หัวใจและหลอดเลือดบางชนิด แม้จะกินยาสม่ำเสมอตามแพทย์สั่งก็ตาม

*แนวทางที่เหมาะสม:* ในผู้ป่วยกลุ่มนี้ แพทย์มักพิจารณาเปลี่ยนไปใช้ยาต้านเกล็ดเลือดชนิดอื่นที่ไม่ต้องพึ่งพา CYP2C19 [6]

***

### เคสที่ 4: คุณอรทัย — "ปกติดี ไม่มีปัญหาอะไรกับยา"

**ข้อมูล:** คุณอรทัย อายุ 50 ปี ใช้ยาหลายชนิดมาตลอดชีวิต ไม่เคยมีปัญหาเรื่องยาไม่ได้ผลหรือผลข้างเคียงรุนแรงผิดปกติ

**ผลตรวจยีน:** CYP2D6 **\*1/\*2**, CYP2C19 **\*1/\*1**

**คำอธิบาย:**

ทั้งสองยีนของคุณอรทัยมีอัลลีลที่ทำงานปกติทั้งคู่ จึงจัดเป็นฟีโนไทป์ **Normal Metabolizer (NM)** ทั้งสองยีน นี่คือกลุ่มที่พบมากที่สุดในประชากรทั่วไป

สำหรับยาที่มีความสัมพันธ์กับยีนดังกล่าว ฟีโนไทป์แบบ Normal Metabolizer มักสอดคล้องกับการตอบสนองต่อขนาดมาตรฐานตามแนวทางที่กำหนด

***

### เคสที่ 5: คุณมานะ — "ทำไมยากลุ่ม PPI ถึงได้ผลไม่เท่ากันในแต่ละคน?"

**ข้อมูล:** คุณมานะ เป็นโรคกรดไหลย้อนเรื้อรัง กินยากลุ่มยับยั้งโปรตอนปั๊ม (Proton Pump Inhibitor, PPI) เช่น Omeprazole ในขนาดมาตรฐานแล้วอาการไม่ดีขึ้นเท่าที่ควร

**ผลตรวจยีน:** CYP2C19 **\*17/\*17**

**คำอธิบาย:**

อัลลีล CYP2C19\*17 จัดเป็นชนิดที่ทำงาน **เพิ่มขึ้น** (Increased function) เมื่อได้รับอัลลีลนี้จากทั้งพ่อและแม่ จัดเป็นฟีโนไทป์ **Ultrarapid Metabolizer (UM)** ตามแนวทาง CPIC สำหรับ CYP2C19 [6,7]

ยา PPI อย่าง Omeprazole ต้องอาศัย CYP2C19 ในการถูกกำจัดออกจากร่างกาย [7] เมื่อเอนไซม์นี้ทำงานเร็วเกินไป ระดับยาในเลือดอาจต่ำกว่าที่ควรจะเป็น ส่งผลให้มีความเสี่ยงต่อการควบคุมกรดในกระเพาะได้ไม่เต็มที่ในขนาดยามาตรฐาน

*แนวทางที่เหมาะสม:* ในบางกรณีแพทย์อาจพิจารณาปรับขนาดยาและติดตามการตอบสนองต่อการรักษา [7]

***

## สรุปท้ายบท

Star Allele คือระบบตั้งชื่อรูปแบบของยีน CYP450 แต่ละแบบ ซึ่งบ่งบอกระดับสมรรถนะการทำงานของเอนไซม์ ตั้งแต่ไม่ทำงานเลยไปจนถึงทำงานเกินปกติ เมื่อนำอัลลีลสองชุดที่แต่ละคนได้รับมารวมกันเป็น Diplotype จะสามารถแปลผลเป็นฟีโนไทป์การเผาผลาญยาได้ ทั้งนี้ระบบ Activity Score ที่ใช้กับ CYP2D6 เป็นเพียงตัวอย่างหนึ่งเท่านั้น ยีนอื่นอย่าง CYP2C19 ใช้เกณฑ์การจัดกลุ่มที่เป็นแบบเฉพาะยีนของตนเอง (เช่น การมีกลุ่ม Rapid Metabolizer แยกต่างหาก) ความเข้าใจทั้งหลักการทั่วไปและข้อจำกัดเฉพาะยีนนี้เป็นพื้นฐานสำคัญที่จะนำไปใช้ตีความรายงานผลตรวจทางเภสัชพันธุศาสตร์ในบทถัดไป

## คำศัพท์สำคัญ

| ศัพท์ | ความหมายโดยย่อ |
|---|---|
| **Star Allele** | รหัสประจำตัว (ตั้งชื่อด้วยเครื่องหมาย * ตามด้วยตัวเลข) ที่บ่งบอกรูปแบบยีนและระดับสมรรถนะของเอนไซม์ ตามระบบของ PharmVar |
| **Normal function allele** | อัลลีลที่โครงสร้างเอนไซม์ไม่ถูกกระทบ ทำงานได้ปกติ เช่น *1, *2 |
| **Decreased function allele** | อัลลีลที่โครงสร้างเอนไซม์เปลี่ยนแปลงบางส่วน ทำงานได้ลดลง เช่น *10 |
| **No function allele** | อัลลีลที่สร้างโปรตีนสมบูรณ์ไม่ได้หรือยีนขาดหายไป ทำให้เอนไซม์ใช้งานไม่ได้เลย เช่น *4, *5 |
| **Increased function allele (Gene duplication)** | อัลลีลที่มีจำนวนสำเนายีนเพิ่มขึ้น ทำให้เอนไซม์ทำงานได้มากกว่าปกติ เช่น *1xN |
| **Diplotype** | คู่ของอัลลีลสองชุดที่ได้รับจากพ่อและแม่ (เช่น CYP2D6 \*1/\*4) |
| **Activity Score (AS)** | ตัวเลขที่ได้จากการรวมคะแนนสมรรถนะ (Activity Value) ของอัลลีลทั้งสองชุด ใช้แปลผล diplotype เป็นฟีโนไทป์ (ใช้กับ CYP2D6 เป็นตัวอย่างหลัก) |
| **Activity Value** | คะแนนสมรรถนะที่กำหนดให้แต่ละอัลลีล ตามระดับการทำงาน (0, 0.25–0.5, 1.0, หรือมากกว่าต่อสำเนา) |
| **Metabolizer Phenotype** | การจัดกลุ่มความสามารถในการเผาผลาญยาของแต่ละบุคคล โดยดูจาก Activity Score หรือการจับคู่ allele function |
| **Poor Metabolizer (PM)** | ฟีโนไทป์ที่เอนไซม์แทบไม่ทำงานเลย (Activity Score = 0) |
| **Intermediate Metabolizer (IM)** | ฟีโนไทป์ที่เอนไซม์ทำงานได้แต่ต่ำกว่าปกติ |
| **Normal Metabolizer (NM)** | ฟีโนไทป์ที่เอนไซม์ทำงานได้ตามมาตรฐาน พบมากที่สุดในประชากร |
| **Rapid Metabolizer (RM)** | ฟีโนไทป์ที่พบเฉพาะบางยีน (เช่น CYP2C19) เอนไซม์ทำงานเร็วกว่ามาตรฐานเล็กน้อยแต่ยังไม่ถึงขั้น UM |
| **Ultrarapid Metabolizer (UM)** | ฟีโนไทป์ที่เอนไซม์ทำงานเร็ว/มากเกินปกติ เกิดจากสำเนายีนซ้ำหรืออัลลีลที่มีฟังก์ชันเพิ่มขึ้น |
| **Indeterminate** | กลุ่มที่ผลตรวจพบอัลลีลที่ยังไม่ทราบระดับการทำงานแน่ชัด (uncertain function allele) |
| **Prodrug** | ยาที่ต้องถูกเปลี่ยนรูปโดยเอนไซม์ก่อนจึงจะออกฤทธิ์ได้จริง (เช่น โคดีน, โคลพิโดเกรล) |
| **Gene-specific interpretation** | หลักการที่เกณฑ์แปลผลฟีโนไทป์เป็นเฉพาะของแต่ละยีน ไม่สามารถนำเกณฑ์ของยีนหนึ่งไปใช้กับอีกยีนหนึ่งได้โดยตรง |

## คำถามทบทวน (5 ข้อ)

1. Star Allele คืออะไร และเพราะเหตุใดตัวเลขที่ตามหลังเครื่องหมายดอกจัน (*) จึงไม่ได้สื่อถึงลำดับความดีหรือแย่ของสมรรถนะเอนไซม์

2. จงอธิบายวิธีคำนวณ Activity Score จาก Diplotype ของ CYP2D6 พร้อมยกตัวอย่างการคำนวณ 1 กรณี และบอกว่า Activity Score นั้นจัดอยู่ในฟีโนไทป์ใด

3. จากเคสคุณสมชาย (CYP2D6 \*4/\*4) และเคสคุณวารี (CYP2D6 \*1/\*1xN) จงอธิบายว่าเหตุใดฟีโนไทป์ที่ต่างกันจึงทำให้ผลของยาโคดีนต่อผู้ป่วยทั้งสองรายแตกต่างกันอย่างสิ้นเชิง

4. เพราะเหตุใดการแปลผลฟีโนไทป์การเผาผลาญยาจึงถือเป็นเรื่อง "เฉพาะยีน" (gene-specific) จงยกตัวอย่างเปรียบเทียบระหว่างระบบของ CYP2D6 กับ CYP2C19 ประกอบคำอธิบาย

5. จากเคสคุณประไพ (CYP2C19 \*2/\*2, Poor Metabolizer) และเคสคุณมานะ (CYP2C19 \*17/\*17, Ultrarapid Metabolizer) จงอธิบายว่าฟีโนไทป์ทั้งสองแบบส่งผลต่อประสิทธิผลของยาโคลพิโดเกรลและยา PPI ตามลำดับอย่างไร เพราะเหตุใดผลจึงออกมาในทิศทางตรงข้ามกัน

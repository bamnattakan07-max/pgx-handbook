# บทที่ 1 รหัสชีวิตกับยา
## "**DNA ทำงานอย่างไร ?"**

ลองนึกภาพตามสถานการณ์ที่อาจจะเกิดขึ้นจริงในชีวิตประจำวันของคุณ ยกตัวอย่าง คุณและเพื่อนสนิทมีอาการปวดศีรษะในคืนเดียวกัน พวกคุณทั้งคู่รับประทานยาแก้ปวดชนิดเดียวกัน

รับประทานยาขนาดยาเท่ากัน แต่ผลลัพธ์กลับตรงกันข้ามราวกับฟ้ากับเหว คุณรู้สึกดีขึ้นภายในครึ่งชั่วโมง ในขณะที่เพื่อนของคุณยังรู้สึกปวดศีรษะ และบอกกล่าวว่ายาไม่ได้ผลเลย ในขณะที่อีกคนในบ้านรับประทานยาตัวเดียวกัน ในขนาดยาที่เท่ากัน

กลับรู้สึกคลื่นไส้จนแทบลุกไม่ขึ้น สถานการณ์นี้ไม่ใช่เรื่องบังเอิญ ไม่ใช่เรื่องของความแข็งแกร่งของร่างกายแต่ละคน และไม่ใช่เรื่องของจิตใจ แต่เป็นเรื่องของรหัสพันธุกรรมที่ซ่อนอยู่ภายในทุกเซลล์ของร่างกายเรา

ซึ่งยาที่ใช้กันอยู่ทั่วไปในปัจจุบันนั้น โดยส่วนใหญ่แล้วเป็นการผลิตขึ้นมาสำหรับผู้ป่วย "ทุกราย" เพื่อที่จะรักษาโรคใดโรคหนึ่งหรือหลายๆโรค แต่ความเป็นจริงคือ ไม่ใช่ผู้ป่วยทุกรายที่จะตอบสนองต่อยาที่ได้รับ อย่างตัวอย่างสถานการณ์ข้างต้น ที่บ่งบอกแล้วว่าลักษณะทางพันธุกรรมของมนุษย์เรานี้เอง ที่มีความหลากหลาย และส่งผลให้ผู้ป่วยแต่ละรายตอบสนองต่อยาได้แตกต่างกัน

และศาสตร์ที่ศึกษาความสัมพันธ์ระหว่างรหัสพันธุกรรมกับการตอบสนองต่อยานั้น มีชื่อว่า 

เภสัชพันธุศาสตร์(Pharmacogenetics) ซึ่งความรู้จากเภสัชพันธุศาสตร์ได้กลายมาเป็นรากฐานสำคัญสำหรับแนวคิด Precision Medicine หรือการแพทย์แม่นยำ ซึ่งมุ่งหวังให้ผู้ป่วยทุกคนได้รับ "ยาที่ใช่" ใน "ขนาดที่ใช่" และเหมาะสมกับพันธุกรรมของแต่ละคน ตั้งแต่ครั้งแรกที่เริ่มการรักษา แทนที่จะพึ่งกระบวนการลองยาผิดถูกที่เสียเวลาและอาจเป็นอันตรายต่อผู้ป่วย ทำให้ผลการรักษาดียิ่งขึ้นและมีผลข้างเคียงน้อยที่สุด

ซึ่งบทนี้จะพาผู้อ่านทุกท่านเดินทางสู่พื้นฐานที่สำคัญที่สุดในการทำความเข้าใจเภสัชพันธุศาสตร์ขั้นพื้นฐาน นั่นคือการทำความเข้าใจว่า DNA ซึ่งเป็นรหัสขีวิตของเราถ่ายทอดข้อมูลไปสู่การสร้างโปรตีนและเอนไซม์ที่ย่อยยาได้อย่างไร และความแตกต่างเพียงเล็กน้อยในรหัสนั้น สามารถเปลี่ยนแปลงผลของการรักษาได้อย่างมีนัยสำคัญ

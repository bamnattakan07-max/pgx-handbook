# บทที่ 5: ยาเปลี่ยนรูป — Prodrug vs. Active Drug

## วัตถุประสงค์การเรียนรู้

หลังจากอ่านบทนี้จบ ผู้อ่านจะสามารถ:
1. อธิบายความหมายของ Prodrug และอธิบายความแตกต่างระหว่าง Prodrug กับ Active Drug
2. อธิบายเหตุผลเชิงเภสัชกรรมที่ทำให้นักเคมียาออกแบบยาบางชนิดให้อยู่ในรูป Prodrug แทนที่จะออกฤทธิ์ได้โดยตรง
3. วิเคราะห์ความสัมพันธ์ระหว่างฟีโนไทป์ของเอนไซม์ CYP450 (โดยเฉพาะ CYP2D6 และ CYP2C19) กับผลทางคลินิกของ Prodrug สำคัญ 4 ชนิด ได้แก่ Codeine, Tramadol, Tamoxifen และ Clopidogrel
4. อธิบายความสำคัญของกรณีศึกษาความเป็นพิษจาก Codeine ในกลุ่ม Ultrarapid Metabolizer และเชื่อมโยงกับคำแนะนำของ CPIC
5. สรุปหลักการทั่วไปในการพิจารณาใช้ยาที่อยู่ในรูป Prodrug กับผู้ป่วยที่มีฟีโนไทป์การเผาผลาญยาแตกต่างกัน

ลองนึกภาพผู้ป่วยหลังผ่าตัดสองคนที่ได้รับยาแก้ปวด Codeine ในขนาดมาตรฐานเท่ากันเป๊ะ คนแรกกินแล้วแทบไม่รู้สึกว่าอาการปวดดีขึ้นเลย ในขณะที่คนที่สองกลับมีอาการง่วงซึมผิดปกติจนต้องเฝ้าระวังการหายใจอย่างใกล้ชิด ทั้งที่ได้ยาตัวเดียวกัน ขนาดเดียวกัน คำถามคือ เหตุใดผลลัพธ์จึงต่างกันได้ถึงเพียงนี้

คำตอบของคำถามนี้เกี่ยวข้องกับกลุ่มยาประเภทหนึ่งที่เรียกว่า **Prodrug** ซึ่งตัวยาเองยังไม่มีฤทธิ์รักษาโดยตรง แต่ต้องอาศัยเอนไซม์ในร่างกายเปลี่ยนรูปให้กลายเป็นสารที่ออกฤทธิ์ได้จริงเสียก่อน และบทที่แล้วได้อธิบายไปแล้วว่าเอนไซม์กลุ่ม CYP450 ที่ทำหน้าที่นี้มีความหลากหลายทางพันธุกรรมสูงมากในแต่ละบุคคล บทนี้จะพาไปดูว่าความหลากหลายดังกล่าวส่งผลต่อยา Prodrug สำคัญที่ใช้กันอยู่ในเวชปฏิบัติอย่างไรบ้าง

---

## 5.1 Prodrug คืออะไร

**Prodrug** คือยาที่เมื่อรับประทานเข้าไปแล้วยังไม่มีฤทธิ์ทางเภสัชวิทยา หรือมีฤทธิ์เพียงเล็กน้อยเท่านั้น ร่างกายจำเป็นต้องเปลี่ยนแปลงโครงสร้างของมันให้กลายเป็น **Active Metabolite** เสียก่อน จึงจะเกิดฤทธิ์รักษาได้จริง ซึ่งแตกต่างจาก **Active Drug** ทั่วไปที่ออกฤทธิ์ได้ทันทีตั้งแต่รูปแบบที่รับประทานเข้าไป โดยไม่ต้องผ่านกระบวนการเปลี่ยนแปลงใด ๆ ก่อน

หากจะเปรียบเทียบให้เห็นภาพ Prodrug ก็เหมือนแป้งโดว์ที่ยังไม่ผ่านการอบ ต้องอาศัยความร้อนจากเตาอบ ซึ่งในที่นี้เปรียบได้กับเอนไซม์ CYP450 ในตับ เปลี่ยนแป้งโดว์ให้กลายเป็นขนมปังที่พร้อมรับประทาน ในขณะที่ Active Drug เปรียบเหมือนขนมปังที่อบเสร็จแล้ว พร้อมกินได้ทันทีโดยไม่ต้องผ่านขั้นตอนใดอีก

เหตุผลที่นักเคมียาเลือกออกแบบยาบางชนิดให้อยู่ในรูป Prodrug นั้นมีหลายประการ บางครั้งเป็นเพราะรูป Prodrug ทนต่อสภาวะกรดในกระเพาะอาหารได้ดีกว่า เช่นกรณีของ Clopidogrel ที่ดูดซึมได้ดีกว่ารูปที่ออกฤทธิ์โดยตรง บางครั้งเป็นเพราะรูป Prodrug ผ่านผนังลำไส้เข้าสู่กระแสเลือดได้ง่ายกว่า ดังตัวอย่างของ Enalapril ซึ่งเป็น Prodrug ของ Enalaprilat หรือบางครั้งก็เพื่อลดผลข้างเคียงก่อนที่ยาจะไปถึงเป้าหมายในร่างกาย และในหลายกรณีการออกแบบเป็น Prodrug ยังช่วยเพิ่ม Bioavailability ได้ด้วย ดังตัวอย่างคลาสสิกของ Valacyclovir ที่ร่างกายจะเปลี่ยนไปเป็น Acyclovir ในที่สุด

---

## 5.2 เพราะเหตุใด Prodrug จึงสำคัญในทางเภสัชพันธุศาสตร์

ในบรรดา Prodrug ทั้งหมดที่ใช้อยู่ในปัจจุบัน มี 4 ชนิดที่มีความสำคัญทางคลินิกเป็นพิเศษ เพราะทั้งหมดล้วนอาศัยเอนไซม์ CYP450 ที่มีความหลากหลายทางพันธุกรรมสูงในการเปลี่ยนรูปให้ออกฤทธิ์ นั่นคือ Codeine และ Tramadol ซึ่งอาศัยเอนไซม์ CYP2D6 เปลี่ยนเป็น Morphine และ O-desmethyltramadol ตามลำดับ, Tamoxifen ซึ่งอาศัยเอนไซม์ CYP2D6 เช่นกันในการเปลี่ยนเป็น Endoxifen และ Clopidogrel ซึ่งอาศัยเอนไซม์ CYP2C19 เปลี่ยนเป็น Thiol metabolite ยาทั้งสี่ชนิดนี้ล้วนได้รับการจัดระดับหลักฐานสูงสุดคือ CPIC Level A และถูกใช้อย่างแพร่หลายในการรักษาอาการปวด มะเร็งเต้านม และการป้องกันลิ่มเลือด ซึ่งจะได้กล่าวถึงรายละเอียดของแต่ละชนิดในหัวข้อถัดไป

## 5.3 Codeine: บทเรียนสำคัญที่คนไทยควรรู้

### กลไกการออกฤทธิ์

เมื่อรับประทาน Codeine เข้าไป ตัวยาเองแทบไม่มีฤทธิ์แก้ปวดเลย เอนไซม์ CYP2D6 จะเปลี่ยน Codeine เพียงประมาณร้อยละ 10 ให้กลายเป็น Morphine ซึ่งเป็นสารที่ออกฤทธิ์แก้ปวดจริง จากนั้น Morphine ที่ได้จะถูกเปลี่ยนต่อโดยเอนไซม์ UGT2B7 ให้กลายเป็น Morphine-6-glucuronide (M6G) ซึ่งก็มีฤทธิ์แก้ปวดร่วมด้วยเช่นกัน

จุดที่น่าสนใจคือ แม้ CYP2D6 จะเปลี่ยน Codeine เป็น Morphine ได้เพียงร้อยละ 10 เท่านั้น แต่ Morphine ที่ได้กลับมีฤทธิ์แรงกว่า Codeine ถึงประมาณ 200 เท่า [1] ด้วยเหตุนี้ แม้จะเป็นเพียงสัดส่วนเล็กน้อยของยาที่ถูกเปลี่ยนรูป แต่ผลทางคลินิกที่ตามมากลับมีนัยสำคัญมาก และนี่คือเหตุผลว่าทำไมความแตกต่างของฟีโนไทป์ CYP2D6 ในแต่ละคนจึงส่งผลต่อความปลอดภัยของการใช้ Codeine ได้อย่างชัดเจน

### ความแตกต่างตามกลุ่มยีน CYP2D6

ผู้ที่จัดอยู่ในกลุ่ม Poor Metabolizer ซึ่งมี Activity Score เท่ากับ 0 แทบไม่สามารถเปลี่ยน Codeine เป็น Morphine ได้เลย ทำให้ผู้ป่วยกลุ่มนี้ยังคงมีอาการปวดอยู่ทั้งที่ได้รับยาแล้ว ในขณะที่กลุ่ม Intermediate Metabolizer ซึ่งมี Activity Score ระหว่าง 0.25 ถึง 1.0 จะได้ Morphine น้อยกว่าปกติ ทำให้แก้ปวดได้เพียงบางส่วน ส่วนกลุ่ม Normal Metabolizer ที่มี Activity Score ระหว่าง 1.25 ถึง 2.25 จะได้รับผลการรักษาตามที่คาดหวังไว้

ที่ต้องระมัดระวังเป็นพิเศษคือกลุ่ม Rapid Metabolizer ซึ่งมี Activity Score ระหว่าง 2.5 ถึง 3.0 อาจได้ Morphine มากกว่าปกติเล็กน้อยจนเกิดผลข้างเคียงเพิ่มขึ้น และโดยเฉพาะอย่างยิ่งกลุ่ม **Ultrarapid Metabolizer** ซึ่งมี Activity Score ตั้งแต่ 3.0 ขึ้นไป จะได้รับ Morphine ในปริมาณมากผิดปกติ จนเสี่ยงต่อภาวะ Morphine toxicity ได้

### กรณีศึกษาที่เปลี่ยนแนวทางการใช้ยาทั่วโลก

เหตุการณ์ที่ทำให้วงการแพทย์ตระหนักถึงอันตรายของ Codeine ในกลุ่ม Ultrarapid Metabolizer อย่างจริงจัง เกิดขึ้นในปี 2009 เมื่อเด็กชายวัย 2 ขวบชาวแคนาดาเสียชีวิตหลังผ่าตัดทอนซิล ทั้งที่ได้รับ Codeine ในขนาดมาตรฐานตามปกติ ผลตรวจพันธุกรรมภายหลังพบว่าเด็กคนนี้มียีน CYP2D6 มากถึง 13 สำเนา จัดอยู่ในกลุ่ม Ultrarapid Metabolizer ทำให้ร่างกายเปลี่ยน Codeine เป็น Morphine ได้เร็วและมากผิดปกติ จนเกิดภาวะกดการหายใจและเสียชีวิตในที่สุด [2]

อีกกรณีหนึ่งเกิดขึ้นในปี 2012 เมื่อทารกอายุเพียง 2 สัปดาห์เสียชีวิตจากสาเหตุใกล้เคียงกัน มารดาที่ให้นมบุตรและเป็น Ultrarapid Metabolizer เช่นกัน ได้รับ Codeine หลังการผ่าตัดคลอด ทำให้ Morphine สะสมอยู่ในน้ำนมในระดับสูง เมื่อทารกได้รับ Morphine ผ่านการดูดนม ก็เกิดภาวะกดการหายใจตามมา [2]

จากสองเหตุการณ์นี้ องค์การอาหารและยาสหรัฐฯ (FDA) จึงออกคำเตือนระดับ Black Box สำหรับ Codeine ในปี 2013 พร้อมทั้งห้ามใช้ในเด็กอายุต่ำกว่า 12 ปี และห้ามใช้ในมารดาที่ให้นมบุตร ซึ่งประเทศไทยและอีกหลายประเทศก็ได้ออกข้อบังคับตามแนวทางเดียวกัน [3]

### แนวทางของ CPIC สำหรับ Codeine

คำแนะนำของ CPIC ฉบับปี 2021 ระบุไว้ชัดเจนว่า ผู้ป่วยกลุ่ม Ultrarapid Metabolizer ไม่ควรใช้ Codeine เนื่องจากเสี่ยงต่อ Morphine toxicity อย่างมาก และควรเปลี่ยนไปใช้ยาที่ออกฤทธิ์โดยตรงแทน เช่น Morphine, Oxycodone หรือ Hydromorphone ซึ่งไม่ใช่ Prodrug ในทางกลับกัน ผู้ป่วยกลุ่ม Poor Metabolizer ก็ไม่แนะนำให้ใช้ Codeine เช่นกัน เพราะยาจะแทบไม่ออกฤทธิ์แก้ปวดเลย จึงควรเปลี่ยนไปใช้ยาในกลุ่มเดียวกันนี้แทน ส่วนกลุ่ม Intermediate Metabolizer อาจแก้ปวดได้น้อยกว่าที่คาด แพทย์จึงควรพิจารณาเปลี่ยนยาหรือปรับขนาดอย่างระมัดระวัง ในขณะที่กลุ่ม Normal Metabolizer และ Rapid Metabolizer สามารถใช้ Codeine ในขนาดปกติได้ [3]

## 5.4 Tramadol: Prodrug ที่มีกลไกซับซ้อนกว่า Codeine

Tramadol มีความซับซ้อนกว่า Codeine ตรงที่ถูกเปลี่ยนรูปผ่านสองช่องทางพร้อมกัน ช่องทางแรกคือเอนไซม์ CYP2D6 ซึ่งเปลี่ยน Tramadol ให้เป็น O-desmethyltramadol หรือที่เรียกกันว่า M1 ซึ่งจับกับ μ-opioid receptor และเป็นตัวออกฤทธิ์แก้ปวดหลัก โดยมีฤทธิ์แรงกว่า Tramadol เดิมถึงประมาณ 200 เท่า ส่วนช่องทางที่สองคือเอนไซม์ CYP3A4 ซึ่งเปลี่ยน Tramadol ให้เป็น N-desmethyltramadol แต่สารตัวนี้ออกฤทธิ์น้อยกว่า M1 มาก

ความแตกต่างที่สำคัญระหว่าง Tramadol กับ Codeine คือ แม้ผู้ป่วยกลุ่ม Poor Metabolizer ของ CYP2D6 จะได้รับ M1 น้อยกว่าปกติ แต่ก็ยังพอมีฤทธิ์แก้ปวดหลงเหลืออยู่บ้างจากช่องทางที่สอง เพียงแต่ผลการรักษาจะน้อยกว่าคนทั่วไปมาก

อย่างไรก็ตาม สิ่งที่ต้องระวังเป็นพิเศษคือผู้ป่วยกลุ่ม Ultrarapid Metabolizer ที่ได้รับ Tramadol จะมีความเสี่ยงเพิ่มขึ้นทั้งจาก Opioid toxicity และจากภาวะ Serotonin Syndrome ซึ่งมีอาการไข้ กล้ามเนื้อกระตุก ชัก และสับสน [3] จึงจำเป็นต้องเฝ้าระวังอาการเหล่านี้อย่างใกล้ชิดในผู้ป่วยกลุ่มนี้

## 5.5 Tamoxifen: Prodrug สำหรับผู้ป่วยมะเร็งเต้านม

Tamoxifen เป็นยาหลักที่ใช้รักษามะเร็งเต้านมชนิดที่มีตัวรับฮอร์โมนเอสโตรเจนเป็นบวก (ER+) ซึ่งพบได้ประมาณร้อยละ 70 ถึง 80 ของผู้ป่วยมะเร็งเต้านมทั้งหมด ตัว Tamoxifen เองมีฤทธิ์ต่ำ และต้องอาศัยเอนไซม์ CYP2D6 เปลี่ยนเป็น 4-Hydroxytamoxifen ซึ่งมีฤทธิ์สูงแต่มีครึ่งชีวิตสั้น ในขณะเดียวกัน Tamoxifen ยังถูกเปลี่ยนโดยเอนไซม์ CYP3A4 และ CYP3A5 ให้เป็น N-Desmethyltamoxifen ก่อน แล้วจึงถูกเปลี่ยนต่อโดย CYP2D6 อีกครั้งให้กลายเป็น **Endoxifen** ซึ่งถือเป็นขั้นตอนที่สำคัญที่สุดในกระบวนการนี้ เพราะ Endoxifen เป็นรูปที่ออกฤทธิ์หลักในการต้านมะเร็ง โดยมีฤทธิ์ต้านเอสโตรเจนสูงกว่า Tamoxifen เดิมถึงประมาณ 100 เท่า และมีครึ่งชีวิตที่ยาวกว่า 4-Hydroxytamoxifen ด้วย ระดับ Endoxifen ที่ตั้งแต่ 5.9 นาโนกรัมต่อมิลลิลิตรขึ้นไป ถือว่าเพียงพอต่อประสิทธิผลในการรักษา [4]

ประเด็นที่ผู้ป่วยมะเร็งเต้านมชาวไทยควรทราบเป็นพิเศษคือ คนไทยประมาณร้อยละ 40 มียีน CYP2D6*10 ซึ่งเอนไซม์ทำงานได้เพียงร้อยละ 25 ของประสิทธิภาพปกติเท่านั้น ทำให้ผู้ป่วยไทยจำนวนไม่น้อยอาจมีระดับ Endoxifen ต่ำกว่าเกณฑ์ที่เพียงพอ และอาจได้รับประโยชน์จาก Tamoxifen น้อยกว่าที่คาดไว้ [4] ด้วยเหตุนี้จึงควรปรึกษาแพทย์เกี่ยวกับการตรวจยีน CYP2D6 ก่อนเริ่มใช้ Tamoxifen ในระยะยาว

สำหรับผู้ป่วยกลุ่ม Poor Metabolizer หรือ Intermediate Metabolizer ที่มี Activity Score ตั้งแต่ 1.0 ลงมา ซึ่งรวมถึงกลุ่ม CYP2D6*10/*10 ที่พบมากในคนไทยด้วยนั้น แนวทางของ CPIC ฉบับปี 2018 แนะนำให้พิจารณาทางเลือกสองแนวทาง คือการเพิ่มขนาด Tamoxifen เป็น 40 มิลลิกรัมต่อวันแทนขนาดปกติ 20 มิลลิกรัมต่อวัน หรือเปลี่ยนไปใช้ยากลุ่ม Aromatase Inhibitor เช่น Letrozole, Anastrozole หรือ Exemestane ซึ่งไม่ต้องอาศัย CYP2D6 ในการออกฤทธิ์ แต่ใช้ได้เฉพาะในผู้ป่วยวัยหมดประจำเดือนเท่านั้น ส่วนผู้ป่วยกลุ่ม Normal Metabolizer หรือ Ultrarapid Metabolizer สามารถใช้ Tamoxifen ในขนาดปกติ 20 มิลลิกรัมต่อวันได้ [4]

นอกจากปัจจัยทางพันธุกรรมแล้ว ยังต้องระมัดระวังการใช้ยาที่ยับยั้งเอนไซม์ CYP2D6 อย่างรุนแรงร่วมกับ Tamoxifen ด้วย เช่น Fluoxetine, Paroxetine และ Bupropion เพราะยาเหล่านี้สามารถลดระดับ Endoxifen ลงได้ถึงร้อยละ 50 ถึง 70 ซึ่งอาจลดประสิทธิผลของการรักษามะเร็งได้อย่างมีนัยสำคัญ

## 5.6 Clopidogrel: Prodrug หัวใจที่คนไทย 1 ใน 10 ต้องระวัง

Clopidogrel หรือที่รู้จักกันในชื่อการค้า Plavix เป็นยาป้องกันลิ่มเลือดที่ใช้อย่างแพร่หลายในผู้ป่วยโรคหัวใจ และมีความสำคัญเป็นพิเศษสำหรับบริบทของประเทศไทย เนื่องจากมีการศึกษาพบว่าคนไทยประมาณร้อยละ 9.2 จัดอยู่ในกลุ่ม Poor Metabolizer ของเอนไซม์ CYP2C19 [6] ซึ่งหมายความว่าผู้ป่วยไทยเกือบ 1 ใน 10 คนที่ได้รับ Clopidogrel อาจไม่ได้รับการปกป้องจากลิ่มเลือดอย่างเพียงพอเลย

กลไกการออกฤทธิ์ของ Clopidogrel ต้องผ่านสองขั้นตอนที่อาศัยเอนไซม์ CYP2C19 ทั้งคู่ ขั้นแรก Clopidogrel ซึ่งไม่มีฤทธิ์ จะถูกเปลี่ยนโดยเอนไซม์ CYP2C19 ร่วมกับ CYP1A2 ให้กลายเป็นสารตัวกลางที่เรียกว่า 2-Oxo-clopidogrel โดยมีเพียงประมาณร้อยละ 15 ของขนาดยาเท่านั้นที่ถูกเปลี่ยนรูปในขั้นนี้ จากนั้นในขั้นที่สอง เอนไซม์ CYP2C19 จะทำหน้าที่สำคัญที่สุดอีกครั้ง ร่วมกับ CYP3A4 และ CYP2B6 เปลี่ยน 2-Oxo-clopidogrel ให้กลายเป็น Thiol metabolite ซึ่งเป็นรูปที่ออกฤทธิ์จริง โดยจะไปจับกับตัวรับ P2Y12 บนเกล็ดเลือด ยับยั้งการเกาะกลุ่มของเกล็ดเลือดที่เกิดจาก ADP และช่วยป้องกันการเกิดลิ่มเลือดในที่สุด

เนื่องจาก CYP2C19 ทำหน้าที่สำคัญในทั้งสองขั้นตอน ผู้ป่วยกลุ่ม Poor Metabolizer จึงสร้าง Thiol metabolite ได้น้อยมากจนแทบไม่มีฤทธิ์ป้องกันลิ่มเลือดเลย ส่งผลให้ความเสี่ยงต่อภาวะหัวใจวายและอัมพาตเพิ่มสูงขึ้นอย่างชัดเจน ผู้ป่วยกลุ่ม Intermediate Metabolizer ก็มีความเสี่ยงเพิ่มขึ้นเช่นกันแม้จะน้อยกว่ากลุ่ม Poor Metabolizer ในขณะที่กลุ่ม Normal Metabolizer จะได้รับการยับยั้งเกล็ดเลือดอย่างเหมาะสม และกลุ่ม Rapid หรือ Ultrarapid Metabolizer จะยับยั้งเกล็ดเลือดได้ดีมากหรือปกติ

แนวทางของ CPIC ฉบับปรับปรุงปี 2022 ระบุว่าผู้ป่วยกลุ่ม Poor Metabolizer ซึ่งมีจีโนไทป์ *2/*2, *2/*3 หรือ *3/*3 ไม่ควรใช้ Clopidogrel โดยเฉพาะในกรณีกลุ่มอาการหลอดเลือดหัวใจเฉียบพลันหรือหลังการทำหัตถการขยายหลอดเลือดหัวใจ ควรเปลี่ยนไปใช้ Prasugrel หรือ Ticagrelor แทน และที่น่าสนใจคือแนวทางฉบับนี้ได้เพิ่มความเข้มงวดสำหรับกลุ่ม Intermediate Metabolizer ซึ่งมีจีโนไทป์ *1/*2 หรือ *1/*3 ด้วย โดย CPIC แนะนำอย่างหนักแน่นให้หลีกเลี่ยง Clopidogrel ในกรณีเดียวกันนี้เช่นกัน ส่วนผู้ป่วยกลุ่ม Normal Metabolizer ที่มีจีโนไทป์ *1/*1 และกลุ่ม Rapid หรือ Ultrarapid Metabolizer ที่มีจีโนไทป์ *1/*17 หรือ *17/*17 สามารถใช้ Clopidogrel ในขนาดปกติได้ [7]

เหตุผลที่ Ticagrelor เป็นทางเลือกที่ดีสำหรับผู้ป่วยกลุ่ม Poor Metabolizer ก็เพราะ Ticagrelor ไม่ใช่ Prodrug แต่ออกฤทธิ์ได้โดยตรงโดยไม่ต้องอาศัย CYP2C19 เลย จึงมีความปลอดภัยสำหรับผู้ป่วยทุกฟีโนไทป์

## 5.7 หลักการสำคัญในการใช้ Prodrug ทางคลินิก

จากเนื้อหาทั้งหมดที่ผ่านมา สามารถสรุปหลักการสำคัญได้ 5 ข้อ ข้อแรกคือ ผู้ป่วยกลุ่ม Poor Metabolizer ที่ได้รับ Prodrug มักจะไม่ได้ผลการรักษา เพราะเอนไซม์ไม่ทำงาน จึงไม่มีการสร้างรูปที่ออกฤทธิ์ขึ้นมา ผู้ป่วยอาจยังคงมีอาการปวดหรือมีความเสี่ยงต่อโรคโดยไม่รู้ตัวว่ายาไม่ได้ผล ข้อที่สองคือ ผู้ป่วยกลุ่ม Ultrarapid Metabolizer ที่ได้รับ Prodrug มีความเสี่ยงต่อพิษจากยาสูง เพราะเอนไซม์ทำงานเร็วเกินไป ทำให้เกิดรูปที่ออกฤทธิ์ในปริมาณที่สูงเกินขีดความปลอดภัย

ข้อที่สามคือ ยาที่ออกฤทธิ์ได้โดยตรงอย่าง Morphine หรือ Ticagrelor ไม่อยู่ภายใต้กฎเหล่านี้ จึงมีความปลอดภัยมากกว่าทั้งในผู้ป่วยกลุ่ม Poor Metabolizer และ Ultrarapid Metabolizer ข้อที่สี่คือ การใช้ยาที่ยับยั้งเอนไซม์ร่วมกับ Prodrug จะยิ่งทำให้ผลการรักษาแย่ลงไปอีก ดังตัวอย่างของ Fluoxetine ที่เมื่อใช้ร่วมกับ Tamoxifen จะทำให้ระดับ Endoxifen ลดลง ส่งผลให้ประสิทธิผลในการรักษามะเร็งลดลงตามไปด้วย และข้อสุดท้ายคือ การตรวจยีนก่อนเริ่มใช้ยาย่อมดีกว่าการแก้ไขปัญหาภายหลัง เพราะการทราบฟีโนไทป์ของผู้ป่วยล่วงหน้าจะช่วยให้แพทย์เลือกยาและขนาดยาที่เหมาะสมได้ตั้งแต่แรกเริ่ม

## สรุปท้ายบท

Prodrug คือยาที่ต้องอาศัยเอนไซม์ในร่างกาย โดยเฉพาะกลุ่ม CYP450 เปลี่ยนแปลงโครงสร้างให้กลายเป็นสารที่ออกฤทธิ์ได้จริง ซึ่งแตกต่างจาก Active Drug ที่ออกฤทธิ์ได้ทันที ยา Prodrug ที่มีความสำคัญทางเภสัชพันธุศาสตร์สูงสุด 4 ชนิด ได้แก่ Codeine และ Tramadol ซึ่งอาศัย CYP2D6 เปลี่ยนเป็น Morphine และ M1 ตามลำดับ, Tamoxifen ซึ่งอาศัย CYP2D6 เปลี่ยนเป็น Endoxifen และ Clopidogrel ซึ่งอาศัย CYP2C19 เปลี่ยนเป็น Thiol metabolite ผู้ป่วยกลุ่ม Poor Metabolizer มักไม่ได้รับผลการรักษาที่เพียงพอจากยาเหล่านี้ ในขณะที่ผู้ป่วยกลุ่ม Ultrarapid Metabolizer มีความเสี่ยงต่อพิษจากยาสูงขึ้น โดยเฉพาะกรณีของ Codeine ที่เคยก่อให้เกิดการเสียชีวิตในเด็กและทารกจนนำไปสู่คำเตือนระดับ Black Box จาก FDA และสำหรับบริบทของประเทศไทย ทั้งความชุกของ CYP2D6*10 ที่ส่งผลต่อ Tamoxifen และความชุกของ CYP2C19 Poor Metabolizer ที่ส่งผลต่อ Clopidogrel ล้วนเป็นประเด็นที่มีนัยสำคัญทางคลินิกอย่างยิ่ง บทที่ 6 จะพาไปสำรวจต่อว่า CPIC แปลงงานวิจัยเหล่านี้ให้กลายเป็นคำแนะนำที่แพทย์นำไปใช้งานจริงได้อย่างไร

## คำศัพท์สำคัญ

| ศัพท์ | ความหมายโดยย่อ |
|---|---|
| **Prodrug** | ยาที่ยังไม่มีฤทธิ์หรือมีฤทธิ์น้อย ต้องผ่านการเปลี่ยนแปลงในร่างกายก่อนจึงออกฤทธิ์ |
| **Active Drug** | ยาที่ออกฤทธิ์ได้ทันทีโดยไม่ต้องผ่านการเปลี่ยนแปลง |
| **Active Metabolite** | สารที่เกิดจากการเปลี่ยนแปลง Prodrug และเป็นรูปที่ออกฤทธิ์จริง |
| **Bioavailability** | สัดส่วนของยาที่เข้าถึงกระแสเลือดจริงหลังผ่านการดูดซึม |
| **CYP2D6 / CYP2C19** | เอนไซม์ในกลุ่ม CYP450 ที่มีบทบาทสำคัญในการเปลี่ยนรูป Prodrug หลายชนิด |
| **Poor Metabolizer (PM)** | ผู้ที่เอนไซม์แทบไม่ทำงาน ทำให้ Prodrug ไม่ถูกเปลี่ยนเป็นรูปออกฤทธิ์ |
| **Ultrarapid Metabolizer (UM)** | ผู้ที่เอนไซม์ทำงานเร็วผิดปกติ เสี่ยงต่อการได้รับ Active Metabolite มากเกินไป |
| **Morphine** | รูปที่ออกฤทธิ์แก้ปวดของ Codeine หลังผ่าน CYP2D6 |
| **Endoxifen** | รูปที่ออกฤทธิ์หลักของ Tamoxifen ในการต้านมะเร็งเต้านม |
| **Thiol metabolite** | รูปที่ออกฤทธิ์ของ Clopidogrel ในการยับยั้งเกล็ดเลือด |
| **CPIC** | Clinical Pharmacogenetics Implementation Consortium หน่วยงานที่ออกแนวทางการใช้ยาตามผลตรวจยีน |
| **Black Box Warning** | คำเตือนระดับสูงสุดของ FDA สำหรับยาที่มีความเสี่ยงร้ายแรง |

## คำถามทบทวน

1. เพราะเหตุใดผู้ป่วยกลุ่ม Ultrarapid Metabolizer ของ CYP2D6 จึงมีความเสี่ยงสูงต่อพิษจาก Codeine ทั้งที่ CYP2D6 เปลี่ยน Codeine เป็น Morphine ได้เพียงประมาณร้อยละ 10 เท่านั้น
2. เปรียบเทียบกลไกการออกฤทธิ์ของ Tramadol กับ Codeine ว่าเหตุใดผู้ป่วยกลุ่ม Poor Metabolizer ที่ได้รับ Tramadol จึงยังพอมีฤทธิ์แก้ปวดหลงเหลืออยู่บ้าง ต่างจากผู้ที่ได้รับ Codeine
3. เพราะเหตุใดความชุกของยีน CYP2D6*10 ในคนไทยจึงมีความสำคัญต่อการใช้ Tamoxifen รักษามะเร็งเต้านม และมีทางเลือกในการรักษาอย่างไรบ้างสำหรับผู้ป่วยกลุ่มนี้
4. อธิบายเหตุผลที่ผู้ป่วยกลุ่ม Poor Metabolizer ของ CYP2C19 ที่ได้รับ Clopidogrel ควรเปลี่ยนไปใช้ Ticagrelor แทน โดยอธิบายในมุมของกลไกที่ Ticagrelor ไม่ใช่ Prodrug
5. จงอธิบายหลักการทั้ง 5 ข้อในการพิจารณาใช้ Prodrug ทางคลินิก และยกตัวอย่างยาที่สอดคล้องกับแต่ละหลักการอย่างน้อยข้อละ 1 ตัวอย่าง

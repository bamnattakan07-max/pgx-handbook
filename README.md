# บทที่ 9: ยีนภูมิคุ้มกัน — HLA และปฏิกิริยาแพ้ยารุนแรง

## วัตถุประสงค์การเรียนรู้

หลังจากอ่านบทนี้จบ ผู้อ่านจะสามารถ:
1. อธิบายความหมายและบทบาทของ HLA ในการนำเสนอสิ่งแปลกปลอมต่อระบบภูมิคุ้มกัน และเชื่อมโยงกับกลไกการเกิดปฏิกิริยาแพ้ยารุนแรง
2. อธิบายลักษณะทางคลินิกและความรุนแรงของ Stevens-Johnson Syndrome และ Toxic Epidermal Necrolysis (SJS/TEN)
3. อธิบายความสัมพันธ์ระหว่าง HLA-B\*57:01 กับการเกิด Hypersensitivity Reaction จาก Abacavir และยกตัวอย่างความสำเร็จของการตรวจยีนก่อนใช้ยาในบริบทนี้
4. วิเคราะห์ความสำคัญของ HLA-B\*15:02 ต่อการใช้ Carbamazepine ในบริบทของประเทศไทย และอธิบายมาตรการที่นำมาใช้จริงในระบบสาธารณสุขไทย
5. ระบุคู่ HLA-ยาอื่น ๆ ที่สำคัญในบริบทไทย และอธิบายหลักการนำผลตรวจ HLA ไปใช้ประกอบการตัดสินใจสั่งยาในทางคลินิก

ลองนึกภาพคุณยายวัย 68 ปีที่มีอาการลมชักและได้รับยา Carbamazepine สัปดาห์แรกทุกอย่างดูปกติดี แต่พอเข้าสัปดาห์ที่สองกลับเริ่มมีไข้สูง ตาแดง ปากเป็นแผล และมีผื่นขึ้นทั่วตัว ภายในสองวันผิวหนังเริ่มหลุดลอกราวกับถูกน้ำร้อนลวก แพทย์วินิจฉัยว่าเป็น Stevens-Johnson Syndrome สิ่งที่ทำให้คุณยายแตกต่างจากคนอื่นที่กิน Carbamazepine แล้วไม่เป็นอะไรเลย คือยีนที่ชื่อว่า HLA-B\*15:02 ซึ่งทำให้ระบบภูมิคุ้มกันมองยาตัวนี้เป็นศัตรูที่ต้องทำลาย

ในประเทศไทยมีคนที่มียีนนี้อยู่ประมาณร้อยละ 6 ถึง 8 ซึ่งหากได้รับ Carbamazepine โดยไม่ได้ตรวจยีนก่อน ก็มีความเสี่ยงสูงมากที่จะเกิดภาวะนี้ขึ้น บทนี้จะพาไปทำความเข้าใจว่ายีน HLA เกี่ยวข้องกับปฏิกิริยาแพ้ยารุนแรงอย่างไร และมีคู่ HLA-ยาใดบ้างที่มีความสำคัญเป็นพิเศษสำหรับคนไทย

## 9.1 HLA คืออะไร: ผู้เฝ้าประตูของระบบภูมิคุ้มกัน

**HLA (Human Leukocyte Antigen)** คือกลุ่มโปรตีนที่อยู่บนผิวเซลล์ ทำหน้าที่นำเสนอชิ้นส่วนของสิ่งแปลกปลอม ไม่ว่าจะเป็นเชื้อโรคหรือยา ให้เซลล์ภูมิคุ้มกันชนิด T-cell มาตรวจสอบว่าสิ่งนั้นคืออะไรและควรจัดการอย่างไร กระบวนการนี้สามารถแสดงเป็นเส้นทางการตัดสินใจได้ดังนี้

```
ยาหรือชิ้นส่วนของยา (Drug / Drug-peptide complex)
                │
    HLA โมเลกุลจับและนำเสนอต่อ T-cell
                │
       T-cell ตัดสินใจ
                │
    ┌───────────┴──────────┐
    │                       │
"ไม่อันตราย"          "อันตราย! โจมตี!"
    │                       │
  ปกติ            ปฏิกิริยาแพ้ยารุนแรง
                   (HSR / SJS/TEN / DRESS)
```

จะเห็นได้ว่าจุดตัดสินใจสำคัญอยู่ที่ขั้นตอนที่ T-cell ประเมินสิ่งที่ HLA นำเสนอ หากอัลลีล HLA ของผู้ป่วยมีรูปร่างที่จับกับยาบางชนิดได้พอดีจนทำให้ T-cell เข้าใจผิดว่าเป็นสิ่งแปลกปลอมอันตราย เส้นทางก็จะนำไปสู่ปฏิกิริยาแพ้ยารุนแรงในที่สุด

ยีน HLA อยู่บนโครโมโซมที่ 6 และมีความหลากหลายทางพันธุกรรมสูงที่สุดในจีโนมมนุษย์ โดยมีอัลลีลมากกว่า 30,000 ชนิด ความหลากหลายนี้เป็นประโยชน์ในแง่ที่ช่วยให้มนุษยชาติสามารถรับมือกับเชื้อโรคได้หลากหลายรูปแบบ แต่ในอีกด้านหนึ่งก็ทำให้อัลลีลบางชนิดจดจำยาบางตัวผิดว่าเป็นอันตราย จนก่อให้เกิดปฏิกิริยาแพ้ยารุนแรงตามมาได้

## 9.2 Stevens-Johnson Syndrome และ Toxic Epidermal Necrolysis

SJS (Stevens-Johnson Syndrome) และ TEN (Toxic Epidermal Necrolysis) ถือเป็นปฏิกิริยาแพ้ยาที่รุนแรงที่สุดชนิดหนึ่ง โดยความรุนแรงจะแบ่งตามสัดส่วนของผิวหนังที่ได้รับผลกระทบ ดังตารางที่ 9.1

| ประเภท | % ผิวหนังที่ได้รับผลกระทบ | อัตราการเสียชีวิต |
|---|---|---|
| SJS | < 10% | ~5–10% |
| SJS/TEN overlap | 10–30% | ~10–30% |
| TEN | > 30% | **~30–50%** |

อาการมักดำเนินไปเป็นลำดับขั้นตามเส้นเวลาต่อไปนี้

```
วันที่ 1–3: ไข้สูง ตาแดง เจ็บคอ
     │
     ▼
วันที่ 3–5: ผื่นในปาก ริมฝีปาก อวัยวะเพศ
     │
     ▼
วันที่ 5–7: ผิวหนังหลุดลอก เป็นแผลพุพอง
     │
     ▼
ภาวะแทรกซ้อน: ติดเชื้อ ตาบอด อวัยวะล้มเหลว เสียชีวิต
```

หากไม่ได้รับการดูแลอย่างทันท่วงทีตั้งแต่ระยะแรกที่ยังเป็นเพียงไข้และผื่น อาการจะไล่ระดับความรุนแรงขึ้นไปตามเส้นทางข้างต้นจนถึงภาวะแทรกซ้อนที่อาจถึงแก่ชีวิตได้ ในบริบทของประเทศไทย ยาที่เป็นสาเหตุของ SJS/TEN บ่อยที่สุด ได้แก่ Carbamazepine, Allopurinol, Phenytoin, Cotrimoxazole และ Lamotrigine

## 9.3 HLA-B\*57:01 และ Abacavir: ต้นแบบความสำเร็จของเภสัชพันธุศาสตร์

Abacavir เป็นยาต้านไวรัส HIV ในกลุ่ม NRTI ซึ่งมักใช้ในสูตรยารวม เช่น Triumeq ที่ประกอบด้วย Abacavir, Lamivudine และ Dolutegravir ปัญหาสำคัญของยาตัวนี้คือการเกิด Hypersensitivity Reaction หรือ HSR ซึ่งพบได้ประมาณร้อยละ 5 ถึง 8 ในผู้ป่วยชาวยุโรปที่ได้รับยา โดยมีอาการไข้ ผื่น คลื่นไส้ และหายใจลำบาก ซึ่งอาจรุนแรงถึงชีวิตได้หากไม่หยุดยาทันที

กลไกของ HSR สามารถแสดงเป็นเส้นทางได้ดังนี้

```
Abacavir จับกับ HLA-B*57:01
    │
    HLA-B*57:01 นำเสนอ Abacavir-peptide complex
    ต่อ CD8+ T-cell
    │
    T-cell คิดว่า "นี่คือศัตรู!"
    │
    ปล่อย Cytotoxic granules + Cytokines
    │
    ทำลายเซลล์ผิวหนัง เยื่อบุ และอวัยวะ
    →  Hypersensitivity Reaction
```

จะเห็นได้ว่าจุดเริ่มต้นของปฏิกิริยาทั้งหมดอยู่ที่การที่ Abacavir สามารถจับกับ HLA-B\*57:01 ได้พอดี หากผู้ป่วยไม่มีอัลลีลนี้ เส้นทางดังกล่าวก็จะไม่เกิดขึ้นตั้งแต่ต้น

ความสำเร็จของการตรวจ HLA-B\*57:01 ก่อนใช้ Abacavir ถือเป็นหนึ่งในตัวอย่างที่สมบูรณ์แบบที่สุดของเภสัชพันธุศาสตร์ทางคลินิก เพราะก่อนมีการตรวจยีน อัตราการเกิด HSR อยู่ที่ประมาณร้อยละ 5 ถึง 8 ของผู้ใช้ยา แต่หลังจากมีการตรวจยีนและหลีกเลี่ยงการใช้ยาในกลุ่มเสี่ยง อัตราการเกิด HSR ลดลงเหลือเกือบร้อยละ 0 [1] จนกลายเป็นตัวอย่างที่ใช้สอนวงการแพทย์ทั่วโลก แนวทางของ CPIC จึงสรุปคำแนะนำไว้ชัดเจนดังตารางที่ 9.2

| ผลตรวจ HLA-B\*57:01 | คำแนะนำ |
|---|---|
| Negative (ไม่มียีนเสี่ยง) | ใช้ Abacavir ได้ตามปกติ |
| Positive (มียีนเสี่ยง) | ห้ามใช้ Abacavir เด็ดขาด ให้เลือกยากลุ่ม NRTI ชนิดอื่นแทน |

ความถี่ของ HLA-B\*57:01 แตกต่างกันไปในแต่ละประชากรอย่างชัดเจน ดังตารางที่ 9.3

| ประชากร | ความถี่ HLA-B\*57:01 |
|---|---|
| ชาวยุโรป | ~5–8% |
| ชาวแอฟริกัน | ~3% |
| คนไทย | < 0.5% |

แม้ในคนไทยจะพบยีนนี้ได้น้อยกว่าประชากรอื่นมาก แต่เนื่องจากผลของปฏิกิริยาที่เกิดขึ้นรุนแรงมากหากเกิดขึ้นจริง จึงยังคงแนะนำให้ตรวจยีนก่อนเริ่มใช้ Abacavir ทุกครั้ง

## 9.4 HLA-B\*15:02 และ Carbamazepine: เรื่องเร่งด่วนสำหรับคนไทย

Carbamazepine เป็นยาที่ใช้รักษาโรคลมชัก อาการปวดเส้นประสาท และโรคอารมณ์สองขั้ว ซึ่งใช้กันอย่างแพร่หลายในประเทศไทย แต่ในผู้ป่วยที่มียีน HLA-B\*15:02 ยาตัวนี้สามารถกระตุ้นให้เกิด SJS/TEN ซึ่งอาจรุนแรงถึงขั้นเสียชีวิตได้ [2] ข้อมูลที่น่าสนใจอย่างมากคือ จากการศึกษาผู้ป่วย SJS/TEN ที่เกิดจาก Carbamazepine ในประเทศไทย พบว่าผู้ป่วยทุกรายล้วนมียีน HLA-B\*15:02 คิดเป็นร้อยละ 100 ของกลุ่มตัวอย่าง [2] ซึ่งหมายความว่า หากมีการตรวจยีนก่อนสั่งจ่ายยาและหลีกเลี่ยงการใช้ในกลุ่มเสี่ยง ก็มีความเป็นไปได้สูงที่จะป้องกันโศกนาฏกรรมเหล่านี้ได้เกือบทั้งหมด

ความถี่ของ HLA-B\*15:02 แตกต่างกันไปตามเชื้อชาติอย่างชัดเจน ดังตารางที่ 9.4

| ประชากร | ความถี่ HLA-B\*15:02 |
|---|---|
| **คนไทย** | **~6–8%** |
| ชาวจีน Han | ~6% |
| ชาวมาเลย์ | ~3–4% |
| ชาวฟิลิปปินส์ | ~3% |
| ชาวยุโรป | < 0.1% |

ด้วยความชุกที่สูงและความรุนแรงของปฏิกิริยาที่อาจเกิดขึ้น โรงพยาบาลหลายแห่งในประเทศไทย รวมถึงโรงพยาบาลรามาธิบดี ได้นำการตรวจ HLA-B\*15:02 เข้าเป็น Standard of Care ก่อนสั่งจ่าย Carbamazepine และได้พัฒนาระบบ Clinical Decision Support หรือ CDS ในระบบเวชระเบียนอิเล็กทรอนิกส์ เพื่อแจ้งเตือนแพทย์โดยอัตโนมัติ ดังเส้นทางการทำงานของระบบต่อไปนี้ [2]

```
แพทย์กำลังสั่ง Carbamazepine
           │
           ▼
ระบบ CDS ตรวจสอบ HLA-B*15:02
           │
    ┌──────┴──────┐
    │              │
 Negative       Positive
    │              │
 ใช้ยาได้      แจ้งเตือนแพทย์
              "ผู้ป่วยมียีนเสี่ยง SJS/TEN"
              "พิจารณายาทางเลือก"
```

สำหรับผู้ป่วยที่ตรวจพบว่ามี HLA-B\*15:02 แพทย์จะพิจารณาเปลี่ยนไปใช้ยาทางเลือกอื่นแทน ดังตารางที่ 9.5

| สถานการณ์ | ยาทางเลือก |
|---|---|
| โรคลมชัก | Valproate, Levetiracetam, Lamotrigine (ต้องปรับขนาดขึ้นอย่างช้า ๆ) |
| ปวดเส้นประสาท | Gabapentin, Pregabalin |
| Bipolar Disorder | Valproate, Lithium, Quetiapine |

## 9.5 คู่ HLA-ยาอื่น ๆ ที่สำคัญในบริบทไทย

นอกเหนือจาก HLA-B\*57:01 กับ Abacavir และ HLA-B\*15:02 กับ Carbamazepine แล้ว ยังมีคู่ HLA-ยาอื่นที่มีความสำคัญทางคลินิกในประเทศไทยเช่นกัน ดังสรุปในตารางที่ 9.6

| HLA Allele | ยา | ปฏิกิริยา | ความถี่ในไทย | สถานะการตรวจในไทย |
|---|---|---|---|---|
| HLA-B\*15:02 | Carbamazepine | SJS/TEN | ~6–8% | เป็น Standard of Care แล้ว |
| HLA-B\*57:01 | Abacavir | HSR | < 0.5% | ตรวจก่อนใช้ยา |
| **HLA-B\*58:01** | **Allopurinol** | **SJS/TEN, DRESS** | **~6–7%** | ยังไม่เป็น Standard ทุกแห่ง |
| HLA-A\*31:01 | Carbamazepine | DRESS, MPE | ~5% | ตรวจในบางกรณี |
| HLA-B\*13:01 | Dapsone | DRESS | พบมากในเอเชียใต้ | ตรวจก่อนใช้ |

คู่ที่ควรให้ความสำคัญเป็นพิเศษอีกคู่หนึ่งคือ HLA-B\*58:01 กับ Allopurinol ซึ่งเป็นยารักษาโรคเก๊าท์ที่ใช้กันอย่างแพร่หลายในประเทศไทย เนื่องจาก HLA-B\*58:01 พบในคนไทยได้ถึงประมาณร้อยละ 6 ถึง 7 ซึ่งใกล้เคียงกับความชุกของ HLA-B\*15:02 ปัจจุบันโรงพยาบาลหลายแห่งในประเทศไทยเริ่มแนะนำให้ตรวจยีนนี้ก่อนเริ่มใช้ยาแล้วเช่นกัน แม้จะยังไม่ได้เป็น Standard of Care ในทุกสถานพยาบาลเหมือนกรณีของ Carbamazepine

## 9.6 หลักการนำผลตรวจ HLA ไปใช้ในทางคลินิก

เมื่อแพทย์พิจารณาสั่งยาที่มีความเสี่ยงสูงต่อการเกิดปฏิกิริยาแพ้ยารุนแรง สามารถนำหลักการต่อไปนี้มาใช้เป็นแนวทางการตัดสินใจได้

```
ก่อนสั่งยาที่มีความเสี่ยงสูง
    │
    ▼
เช็คว่าผู้ป่วยเคยตรวจ HLA ที่เกี่ยวข้องหรือยัง?
    │
    ├── เคยตรวจแล้ว → ดูผลและตัดสินใจ
    │
    └── ยังไม่เคยตรวจ → ตรวจก่อน (ในกรณีไม่เร่งด่วน)
                         หรือเริ่มด้วยยาทางเลือกที่ปลอดภัยกว่า

ถ้าผล Negative (ไม่มียีนเสี่ยง):
    └── ใช้ยาได้ แต่ยังต้องเฝ้าระวังอาการแพ้ทั่วไป

ถ้าผล Positive (มียีนเสี่ยง):
    └── หลีกเลี่ยงยานั้น เลือกทางเลือกที่ปลอดภัยกว่า
```

ข้อสำคัญที่ต้องเน้นย้ำคือ ผลตรวจที่เป็นลบไม่ได้รับประกันความปลอดภัยได้ร้อยเปอร์เซ็นต์ เพราะ HLA เป็นเพียงปัจจัยเสี่ยงหนึ่งเท่านั้น ยังมีกลไกอื่นที่สามารถก่อให้เกิดปฏิกิริยาแพ้ยาได้เช่นกัน แพทย์และผู้ป่วยจึงยังคงต้องเฝ้าระวังอาการแพ้ยาอยู่เสมอ ไม่ว่าผลตรวจยีนจะเป็นอย่างไรก็ตาม

---

## สรุปท้ายบท

HLA เป็นกลุ่มโปรตีนบนผิวเซลล์ที่ทำหน้าที่นำเสนอสิ่งแปลกปลอมต่อระบบภูมิคุ้มกัน และมีความหลากหลายทางพันธุกรรมสูงที่สุดในจีโนมมนุษย์ ความหลากหลายนี้เองที่เป็นสาเหตุให้ยาบางชนิดถูกระบบภูมิคุ้มกันมองว่าเป็นศัตรู จนนำไปสู่ปฏิกิริยาแพ้ยารุนแรงอย่าง SJS/TEN, HSR หรือ DRESS ดังสรุปในตารางที่ 9.7

| HLA Allele | ยา | ปฏิกิริยา | คำแนะนำหลัก |
|---|---|---|---|
| HLA-B\*57:01 | Abacavir | HSR | ตรวจก่อนใช้ทุกครั้ง |
| HLA-B\*15:02 | Carbamazepine | SJS/TEN | เป็น Standard of Care ในไทยแล้ว |
| HLA-B\*58:01 | Allopurinol | SJS/TEN, DRESS | ตรวจก่อนใช้ในหลายโรงพยาบาลไทย |
| HLA-A\*31:01 | Carbamazepine | DRESS | ตรวจในบางกรณี |

กรณีของ HLA-B\*57:01 กับ Abacavir ถือเป็นตัวอย่างความสำเร็จที่สมบูรณ์แบบของเภสัชพันธุศาสตร์ในการลดอัตราการเกิด HSR ลงเกือบเป็นศูนย์ ในขณะที่กรณีของ HLA-B\*15:02 กับ Carbamazepine แสดงให้เห็นถึงความสำคัญของบริบททางเชื้อชาติ เพราะความชุกของยีนนี้ในคนไทยสูงกว่าชาวยุโรปหลายสิบเท่า จนนำไปสู่การกำหนดให้เป็น Standard of Care ในระบบสาธารณสุขไทย บทที่ 10 จะพาไปสำรวจปฏิกิริยาที่ซับซ้อนยิ่งขึ้น เมื่อยา ยีน และยาอีกตัวมาอยู่ในร่างกายเดียวกันพร้อมกัน

## คำศัพท์สำคัญ

| ศัพท์ | ความหมายโดยย่อ |
|---|---|
| **HLA (Human Leukocyte Antigen)** | กลุ่มโปรตีนบนผิวเซลล์ที่นำเสนอสิ่งแปลกปลอมต่อ T-cell |
| **T-cell** | เซลล์ภูมิคุ้มกันที่ตัดสินใจว่าจะโจมตีสิ่งที่ HLA นำเสนอหรือไม่ |
| **SJS (Stevens-Johnson Syndrome)** | ปฏิกิริยาแพ้ยารุนแรงที่ทำให้ผิวหนังหลุดลอก ครอบคลุมพื้นที่ผิวน้อยกว่า 10% |
| **TEN (Toxic Epidermal Necrolysis)** | ปฏิกิริยาแพ้ยารุนแรงชนิดเดียวกับ SJS แต่ครอบคลุมพื้นที่ผิวมากกว่า 30% |
| **HSR (Hypersensitivity Reaction)** | ปฏิกิริยาไวเกินของระบบภูมิคุ้มกันต่อยา เช่นที่เกิดกับ Abacavir |
| **DRESS** | ปฏิกิริยาแพ้ยารุนแรงที่มีไข้ ผื่น และอวัยวะภายในอักเสบร่วมด้วย |
| **HLA-B\*57:01** | อัลลีลที่สัมพันธ์กับการเกิด HSR จาก Abacavir |
| **HLA-B\*15:02** | อัลลีลที่สัมพันธ์กับการเกิด SJS/TEN จาก Carbamazepine โดยเฉพาะในคนไทย |
| **HLA-B\*58:01** | อัลลีลที่สัมพันธ์กับการเกิด SJS/TEN และ DRESS จาก Allopurinol |
| **Clinical Decision Support (CDS)** | ระบบแจ้งเตือนอัตโนมัติในเวชระเบียนอิเล็กทรอนิกส์เพื่อช่วยแพทย์ตัดสินใจสั่งยา |

## คำถามทบทวน

1. อธิบายกลไกที่ HLA และ T-cell ทำงานร่วมกันจนนำไปสู่การเกิดปฏิกิริยาแพ้ยารุนแรง โดยใช้กรณีของ Abacavir และ HLA-B\*57:01 เป็นตัวอย่างประกอบ
2. เพราะเหตุใดกรณีของ HLA-B\*57:01 กับ Abacavir จึงถูกยกให้เป็นตัวอย่างความสำเร็จที่สมบูรณ์แบบของเภสัชพันธุศาสตร์ทางคลินิก
3. จงอธิบายว่าทำไมความชุกของ HLA-B\*15:02 ในคนไทยจึงทำให้การตรวจยีนนี้กลายเป็น Standard of Care ก่อนสั่งจ่าย Carbamazepine ในประเทศไทย ต่างจากในประชากรยุโรปอย่างไร
4. หากผู้ป่วยมีผลตรวจ HLA-B\*15:02 เป็นบวกและต้องการยารักษาโรคลมชัก มีทางเลือกใดบ้างที่แพทย์ควรพิจารณา
5. เพราะเหตุใดผลตรวจ HLA ที่เป็นลบจึงไม่สามารถรับประกันได้ว่าผู้ป่วยจะไม่เกิดอาการแพ้ยา และเหตุใดจึงยังคงต้องเฝ้าระวังอาการแพ้ยาอยู่เสมอ

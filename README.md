# บทที่ 1: รหัสชีวิตกับยา — DNA ทำงานอย่างไร?

## วัตถุประสงค์การเรียนรู้

หลังจากอ่านบทนี้จบ ผู้อ่านจะสามารถ:
1. อธิบายหลักการ Central Dogma และเชื่อมโยงให้เห็นว่าเกี่ยวข้องกับการสร้างเอนไซม์ที่เผาผลาญยาอย่างไร
2. อธิบายความหมายของ SNP (Single Nucleotide Polymorphism) และยกตัวอย่างผลกระทบต่อการทำงานของเอนไซม์
3. อธิบายความหมายของยีน อัลลีล ระบบ Star Allele, Diplotype และ Activity Score
4. จำแนกฟีโนไทป์การเผาผลาญยาทั้งห้ากลุ่ม พร้อมอธิบายนัยทางคลินิกของแต่ละกลุ่ม
5. อธิบายว่าเหตุใดความถี่อัลลีลจึงแตกต่างกันระหว่างประชากร และเหตุใดเรื่องนี้จึงสำคัญในบริบทของคนไทย
6. บอกบทบาทของฐานข้อมูลหลักด้านเภสัชพันธุศาสตร์ได้ (PharmVar, PharmGKB, CPIC)

ลองนึกภาพว่าคุณกับเพื่อนสนิทปวดหัวพร้อมกันคืนหนึ่ง ทั้งคู่กินยาแก้ปวดชนิดเดียวกัน ขนาดเท่ากันเป๊ะ แต่ผลลัพธ์กลับตรงข้ามกันราวฟ้ากับเหว คุณรู้สึกดีขึ้นภายในครึ่งชั่วโมง ส่วนเพื่อนของคุณยังปวดหัวอยู่เหมือนเดิมและบอกว่ายาไม่ได้ผลเลย ในขณะที่อีกคนในบ้านที่กินยาตัวเดียวกัน ขนาดเดียวกัน กลับรู้สึกคลื่นไส้จนแทบลุกไม่ขึ้น

เหตุการณ์แบบนี้ไม่ใช่เรื่องบังเอิญ ไม่เกี่ยวกับความแข็งแรงของร่างกาย และไม่เกี่ยวกับจิตใจ แต่เป็นเรื่องของ **รหัสพันธุกรรม** ที่ซ่อนอยู่ในทุกเซลล์ของร่างกายเรา

ยาส่วนใหญ่ที่ใช้กันอยู่ทุกวันนี้ถูกผลิตขึ้นมาสำหรับผู้ป่วย "ทุกคน" เพื่อรักษาโรคใดโรคหนึ่ง แต่ความจริงคือไม่ใช่ทุกคนที่จะตอบสนองต่อยาแบบเดียวกัน เพราะความแตกต่างทางพันธุกรรมของแต่ละคนนี่เองที่ทำให้ร่างกายจัดการกับยาต่างกันไป

ศาสตร์ที่ศึกษาความสัมพันธ์ระหว่างรหัสพันธุกรรมกับการตอบสนองต่อยา เรียกว่า **เภสัชพันธุศาสตร์ (Pharmacogenetics)** ซึ่งเป็นรากฐานสำคัญของแนวคิด **Precision Medicine** หรือการแพทย์แม่นยำ ที่มุ่งหวังให้ผู้ป่วยทุกคนได้รับ "ยาที่ใช่" ใน "ขนาดที่ใช่" ตั้งแต่ครั้งแรกที่เริ่มการรักษา แทนที่จะต้องลองผิดลองถูกซึ่งเสียเวลาและอาจเป็นอันตราย [1]

บทนี้จะพาไปทำความเข้าใจพื้นฐานที่สำคัญที่สุด นั่นคือ DNA ถ่ายทอดข้อมูลไปสู่การสร้างเอนไซม์ที่ย่อยยาได้อย่างไร และทำไมความแตกต่างเพียงเล็กน้อยในรหัสนั้นถึงเปลี่ยนผลการรักษาได้อย่างมาก

## 1.1 Central Dogma: พิมพ์เขียวของชีวิต

ก่อนจะเข้าใจว่า DNA เกี่ยวข้องกับยาอย่างไร เราต้องรู้จักหลักการพื้นฐานที่สุดของชีววิทยาโมเลกุลก่อน นั่นคือ **Central Dogma** ซึ่ง Francis Crick เสนอไว้ในปี ค.ศ. 1958 [2] หลักการนี้อธิบายว่าข้อมูลพันธุกรรมไหลจาก DNA ไปเป็น RNA (เรียกว่า Transcription) แล้วจึงกลายเป็นโปรตีนในที่สุด (เรียกว่า Translation) โปรตีนที่ถูกสร้างขึ้นนี้เองที่กลายเป็นเอนไซม์สำคัญ ๆ ในร่างกาย เช่น เอนไซม์ย่อยอาหาร และเอนไซม์เผาผลาญยา

ให้ลองนึกภาพกระบวนการนี้เป็นสายการผลิตสามขั้นตอนที่ทำงานอยู่ในทุกเซลล์ตลอดเวลา

**ขั้นที่ 1 — DNA: ห้องสมุดพิมพ์เขียวขนาดใหญ่**

DNA หรือกรดดีออกซีไรโบนิวคลีอิก (Deoxyribonucleic acid) ประกอบด้วยตัวอักษรหน่วยย่อย 4 ชนิด คือ A (Adenine), T (Thymine), G (Guanine) และ C (Cytosine) เรียงต่อกันเป็นสายยาวรูปเกลียวคู่ จีโนมของมนุษย์มีลำดับเบสทั้งหมดถึง 3,200 ล้านคู่เบส [3] หากพิมพ์ลำดับเบสทั้งหมดลงในหนังสือ จะได้หนังสือหนาไม่ต่ำกว่า 1,000 เล่ม แต่ร่างกายของเราสามารถอ่านและแปลรหัสทั้งหมดนี้ได้ภายในเวลาไม่กี่นาที

DNA ทำหน้าที่เหมือน "ห้องสมุดพิมพ์เขียว" ที่เก็บข้อมูลทั้งหมดไว้อย่างปลอดภัยในนิวเคลียสของเซลล์ ข้อมูลนี้จะไม่ถูกนำออกไปใช้โดยตรง แต่จะมีการ "ถ่ายสำเนา" ออกมาในรูปแบบ mRNA เพื่อนำไปสร้างโปรตีนแทน เหมือนห้องสมุดที่อนุญาตให้ถ่ายเอกสารออกไปใช้ข้างนอกได้ แต่ต้นฉบับต้องเก็บไว้ในห้องสมุดเสมอ

**ขั้นที่ 2 — mRNA: ใบสั่งทำของที่ส่งต่อข้อมูล**

เมื่อร่างกายต้องการสร้างโปรตีนชนิดใดชนิดหนึ่ง เซลล์จะเริ่มกระบวนการที่เรียกว่า **Transcription** เอนไซม์ RNA Polymerase จะอ่านลำดับเบสจาก DNA แล้วถ่ายทอดออกมาเป็น **mRNA (messenger RNA)** ซึ่งเป็นโมเลกุลขนาดเล็กพร้อมเดินทางออกจากนิวเคลียสไปยังไรโบโซมในไซโตพลาสซึม เปรียบเหมือนใบสั่งทำของที่ถูกส่งจากห้องออกแบบไปยังโรงงานผลิต

**ขั้นที่ 3 — โปรตีน: ผลิตภัณฑ์สำเร็จรูปที่ทำงานจริง**

ขั้นตอนสุดท้ายเรียกว่า **Translation** ไรโบโซมจะอ่านรหัสบน mRNA แล้วประกอบกรดอะมิโนเข้าด้วยกันทีละหน่วย จนได้โปรตีนที่มีรูปร่างและหน้าที่เฉพาะเจาะจง โปรตีนเหล่านี้ทำหน้าที่เป็น "เอนไซม์" ที่ขับเคลื่อนกระบวนการทางชีวเคมีทุกอย่างในร่างกาย รวมถึงการย่อยสลายยาที่เรากลืนเข้าไปด้วย

> **จุดที่เชื่อมกับยา**
> เอนไซม์ที่ย่อยสลายยาในตับล้วนเป็นโปรตีนที่ถูกสร้างขึ้นผ่านกระบวนการ Central Dogma ทั้งสิ้น ถ้า DNA ของใครมีความแตกต่างในตำแหน่งสำคัญ โปรตีนหรือเอนไซม์ที่สร้างออกมาก็อาจทำงานดีกว่า แย่กว่า หรือไม่ทำงานเลย ซึ่งส่งผลโดยตรงต่อวิธีที่ร่างกายจัดการกับยา

## 1.2 SNP: เมื่อตัวอักษรเดียวเปลี่ยนทุกอย่าง

จีโนมของมนุษย์มีความเหมือนกันสูงถึง 99.9% หากพิจารณาเฉพาะความต่างแบบเบสเดี่ยว (SNP) แต่ถ้านับรวมความแปรปรวนแบบอื่นด้วย เช่น การขาดหรือเพิ่มขึ้นของชิ้นส่วน DNA ความเหมือนกันจะลดลงเหลือประมาณ 99.6% [3] ความต่างเพียงเล็กน้อยนี้เองที่กำหนดลักษณะเฉพาะบุคคล ทั้งสีตา ลักษณะผม สีผิว และรวมถึงความสามารถในการตอบสนองต่อยาด้วย

**SNP** คือการเปลี่ยนแปลงตัวอักษรลำดับเบสใน DNA เพียงหนึ่งตำแหน่ง โดยนิวคลีโอไทด์หนึ่งตัวถูกแทนที่ด้วยอีกตัวหนึ่ง เช่น A เปลี่ยนเป็น G เป็นความแปรผันที่พบได้บ่อยในประชากร (ตั้งแต่ 1% ขึ้นไป) โดยเฉลี่ยจะพบ SNP ประมาณ 1 ตำแหน่งต่อทุก ๆ 1,000 คู่เบส ทำให้มีอยู่ทั่วจีโนมมากกว่า 4 ล้านตำแหน่งต่อคน [3]

ลองดูตัวอย่างง่าย ๆ สมมติเรามีประโยคว่า **THE CAT SAT ON THE MAT** แล้วเกิด SNP เปลี่ยนตัวอักษร C เป็น B ประโยคจะกลายเป็น **THE BAT SAT ON THE MAT** ความหมายเปลี่ยนไปทันที นี่คือหลักการเดียวกับที่เกิดขึ้นในจีโนมมนุษย์ หากตำแหน่งอักษรใน DNA เปลี่ยน โปรตีนที่ผลิตออกมาก็อาจเปลี่ยนตามไปด้วย

อย่างไรก็ตาม SNP ส่วนใหญ่ไม่ก่อให้เกิดการเปลี่ยนแปลงใด ๆ ต่อร่างกาย เพราะอยู่ในตำแหน่งที่ยีนไม่ได้แสดงออก แต่เมื่อไหร่ที่ SNP เกิดขึ้นใน coding region (บริเวณที่ยีนใช้สร้างโปรตีน) โดยเฉพาะในยีนที่สร้างเอนไซม์ย่อยยากลุ่ม CYP450 มันสามารถเปลี่ยนแปลงโครงสร้างและการทำงานของเอนไซม์ได้อย่างมีนัยสำคัญทางคลินิก

ตัวอย่างที่ถูกศึกษามากที่สุดคือ **CYP2D6\*4** ซึ่งเกิดจาก SNP ที่ตำแหน่ง c.1846G>A [4] ทำให้เกิด **splicing defect** หรือความผิดปกติในขั้นตอนตัดต่อ mRNA (ขั้นตอนที่เซลล์ตัดชิ้นส่วนที่ไม่จำเป็นออกจาก mRNA ก่อนนำไปแปลเป็นโปรตีน) เมื่อการตัดต่อผิดพลาด mRNA ที่ได้จะไม่สมบูรณ์ ทำให้เอนไซม์ที่สร้างออกมาไม่ทำงาน ยาหลายชนิดที่ควรถูกเอนไซม์นี้เผาผลาญจึงสะสมในร่างกายมากผิดปกติจนอาจเป็นอันตรายได้

## 1.3 ยีน อัลลีล และ Diplotype: ภาษาที่ต้องรู้

เพื่อสื่อสารเรื่องความแตกต่างทางพันธุกรรมได้ชัดเจน นักวิทยาศาสตร์และแพทย์ใช้คำศัพท์เฉพาะที่มีนิยามแน่นอน ผู้อ่านควรทำความเข้าใจคำเหล่านี้ก่อนไปต่อ

**ยีน (Gene)**

ยีนคือหน่วยพื้นฐานของการถ่ายทอดพันธุกรรม หมายถึงส่วนหนึ่งของ DNA ที่มีรหัสสำหรับสร้างโปรตีนหรือ RNA ชนิดใดชนิดหนึ่งโดยเฉพาะ

เดิมทีโครงการ *Human Genome Project* เคยระบุว่ามนุษย์มียีนที่สร้างโปรตีนราว 25,000 ยีน แต่ปัจจุบันข้อมูลจากเทคโนโลยีใหม่อย่าง RNA-seq และ Long-read sequencing ยืนยันว่าตัวเลขนี้เสถียรอยู่ที่ไม่เกิน 20,000 ยีน (ประมาณ 19,000–19,900 ยีน) ตัวเลขในอดีตที่สูงเกินไปเกิดจากการนับรวมยีนที่ไม่ทำงานจริง (Pseudogenes) และส่วนที่ไม่สร้างโปรตีน (Non-coding RNA) เข้าไปด้วย [11] ความซับซ้อนของร่างกายมนุษย์จึงไม่ได้มาจากจำนวนยีน แต่มาจากวิธีที่ยีนเหล่านั้นทำงานร่วมกันและถูกควบคุม

**อัลลีลและ Star Allele**

มนุษย์เป็นสิ่งมีชีวิตที่มีโครโมโซมเป็นคู่ (diploid organism) เราจึงมียีนทุกยีนอยู่สองชุด ชุดหนึ่งได้รับจากพ่อ อีกชุดได้รับจากแม่ รูปแบบต่าง ๆ ของยีนชนิดเดียวกันเรียกว่า **อัลลีล (Allele)** ในเภสัชพันธุศาสตร์ อัลลีลของยีนที่เกี่ยวกับการย่อยยาจะถูกตั้งชื่อตามระบบ **Star Allele** ซึ่งดูแลโดย PharmVar Consortium [4] ตัวอย่างเช่น

- CYP2D6\*1 คืออัลลีลปกติที่ทำงานเต็มประสิทธิภาพ
- CYP2D6\*4 คืออัลลีลที่ไม่ทำงาน
- CYP2D6\*10 คืออัลลีลที่ทำงานได้ลดลง ซึ่งพบบ่อยในชาวเอเชีย

**Diplotype และ Activity Score**

เมื่อนำอัลลีลทั้งสองที่ได้รับจากพ่อและแม่มาระบุร่วมกัน จะเรียกว่า **Diplotype** เช่น CYP2D6 \*1/\*4 หมายความว่าบุคคลนั้นได้รับอัลลีลปกติหนึ่งชุดและอัลลีลที่ไม่ทำงานหนึ่งชุด

จาก Diplotype เราสามารถคำนวณ **Activity Score (AS)** ได้ โดยแต่ละอัลลีลจะได้คะแนนตามระดับการทำงานของเอนไซม์ที่สร้างออกมา อัลลีลปกติได้คะแนน 1.0 อัลลีลที่ทำงานลดลงได้ 0.5 หรือ 0.25 และอัลลีลที่ไม่ทำงานได้ 0 คะแนน คะแนนรวมจาก Diplotype นี้จะบอกว่าบุคคลนั้นจัดอยู่ในฟีโนไทป์แบบไหน ซึ่งจะอธิบายในหัวข้อถัดไป

## 1.4 ฟีโนไทป์ทั้งห้า: จากยีนสู่การตอบสนองต่อยา

เมื่อรู้ Activity Score แล้ว นักเภสัชพันธุศาสตร์จะจัดบุคคลออกเป็นห้ากลุ่มตามความสามารถในการเผาผลาญยา เรียกว่า **ฟีโนไทป์การเผาผลาญ (Metabolizer Phenotype)** [5] การเข้าใจกลุ่มเหล่านี้สำคัญมากสำหรับการนำเภสัชพันธุศาสตร์ไปใช้จริงในทางคลินิก

**Poor Metabolizer (PM)** — Activity Score เท่ากับ 0 หมายความว่าเอนไซม์ไม่ทำงานหรือทำงานน้อยมากจนแทบไม่มีนัยสำคัญ ผลที่เกิดขึ้นต่างกันในสองสถานการณ์ หากยานั้นเป็นยาที่ออกฤทธิ์โดยตรง (Active Drug) ยาจะสะสมในกระแสเลือดและอาจก่อพิษรุนแรง แต่ถ้าเป็น Prodrug ที่ต้องถูกเอนไซม์เปลี่ยนเป็นรูปออกฤทธิ์ก่อน ยานั้นจะไม่ได้ผลเลย

**Intermediate Metabolizer (IM)** — Activity Score อยู่ในช่วง 0.25–1.0 เอนไซม์ทำงานได้บางส่วน การย่อยสลายยาช้ากว่าปกติแต่ยังพอมีประสิทธิภาพ กลุ่มนี้อาจต้องปรับขนาดยาในบางชนิด โดยเฉพาะยาที่มีช่วงการรักษาแคบ (Therapeutic Window แคบ)

**Normal Metabolizer (NM)** — Activity Score อยู่ในช่วง 1.25–2.25 เป็นกลุ่มที่เอนไซม์ทำงานได้ตามปกติ การใช้ยาในขนาดมาตรฐานตามเอกสารกำกับยามักได้ผลดีกับคนกลุ่มนี้ เพราะยาส่วนใหญ่ถูกออกแบบมาสำหรับคนกลุ่มนี้เป็นหลัก

**Rapid Metabolizer (RM)** — Activity Score อยู่ในช่วง 2.5–3.0 เอนไซม์ทำงานดีกว่าปกติ ยาถูกกำจัดออกเร็วกว่า ผู้ป่วยกลุ่มนี้อาจรู้สึกว่ายาในขนาดปกติไม่ค่อยได้ผล แพทย์อาจต้องพิจารณาเพิ่มขนาดยาหรือความถี่ในการให้ยา

**Ultrarapid Metabolizer (UM)** — Activity Score ตั้งแต่ 3.0 ขึ้นไป เอนไซม์ทำงานมากผิดปกติ ส่วนใหญ่เกิดจากยีน CYP2D6 ถูกจำลองซ้ำหลายชุด [10] เรียกว่า **Gene Duplication** (คือการที่บุคคลนั้นมียีนตัวเดิมซ้ำกันมากกว่าหนึ่งชุดในตำแหน่งเดียวกัน ทำให้ร่างกายผลิตเอนไซม์ออกมามากกว่าคนทั่วไป) สำหรับ Active Drug ยาจะถูกกำจัดเร็วมากจนแทบไม่มีโอกาสออกฤทธิ์ แต่สำหรับ Prodrug อย่าง Codeine ผู้ที่มีฟีโนไทป์นี้จะเปลี่ยน Codeine เป็น Morphine เร็วมากและผิดปกติ จนอาจเกิดภาวะกดการหายใจซึ่งเป็นอันตรายถึงชีวิตได้ โดยเฉพาะในเด็ก

### กรณีศึกษา: อันตรายถึงชีวิตจากการใช้โคเดอีนหลังผ่าตัดทอนซิลในเด็ก

ในปี พ.ศ. 2552 มีรายงานว่าเด็กวัยหัดเดินคนหนึ่งเสียชีวิตหลังได้รับยาโคเดอีนเพื่อบรรเทาปวด หลังเข้ารับการผ่าตัดต่อมอะดีนอยด์และต่อมทอนซิลเพื่อรักษาภาวะหยุดหายใจขณะหลับ (Obstructive Sleep Apnea) ผลตรวจพบว่าเด็กคนนี้มีพันธุกรรมแบบ Ultrarapid Metabolizer (UM) คือเผาผลาญยาผ่านเอนไซม์ CYP2D6 ได้เร็วผิดปกติมาก

ต่อมามีรายงานผู้เสียชีวิตเพิ่มอีก 2 ราย และพบภาวะกดการหายใจรุนแรงอีก 1 รายในทวีปอเมริกาเหนือ ทุกกรณีเกิดจากสาเหตุเดียวกันคือ Gene Duplication ของยีน CYP2D6 ทำให้ร่างกายเปลี่ยนโคเดอีนเป็นมอร์ฟีนในปริมาณสูงเกินไปจนเกิด Overdose [6]

กรณีเหล่านี้แสดงให้เห็นว่าการใช้โคเดอีนหรือยาแก้ปวดกลุ่มโอปิออยด์อื่นที่ผ่าน CYP2D6 หลังผ่าตัดต่อมทอนซิล อาจไม่ปลอดภัยในเด็กเล็กที่มีภาวะหยุดหายใจขณะหลับชนิดอุดกั้น จากกรณีศึกษานี้ FDA จึงออกคำเตือนระดับ Black Box และหลายประเทศรวมถึงไทยห้ามใช้โคเดอีนในเด็กอายุต่ำกว่า 12 ปี และในมารดาที่ให้นมบุตร [7]

## 1.5 ทำไมเราถึงมี DNA ที่แตกต่างกัน

ทำไมธรรมชาติถึงสร้างให้เราแตกต่างกัน? คำตอบมาจากวิวัฒนาการอันยาวนาน เพื่อความอยู่รอดของเผ่าพันธุ์ ตัวแปรสำคัญเกิดขึ้นตอนปฏิสนธิ ผ่านกระบวนการแบ่งเซลล์สืบพันธุ์ (Meiosis) ซึ่งมีการผสมผสานและสลับชิ้นส่วนยีนของพ่อและแม่เข้าด้วยกัน ทำให้ลูกแต่ละคนได้รับชุดยีนที่ตอบสนองต่อยาแตกต่างกัน แม้จะเป็นพี่น้องท้องเดียวกันก็ตาม

ผลลัพธ์ของกระบวนการนี้คือความถี่อัลลีลที่แตกต่างกันระหว่างประชากรในแต่ละภูมิภาค ซึ่งมีความสำคัญทางคลินิกอย่างมาก ตัวอย่างที่ชัดเจนในบริบทไทยคืออัลลีล **CYP2C19\*2** ซึ่งทำให้เอนไซม์ CYP2C19 ไม่ทำงาน อัลลีลนี้พบในคนไทยประมาณร้อยละ 25–29 สูงกว่าชาวยุโรปที่พบเพียงร้อยละ 13–15 [9]

หากนับเฉพาะผู้ที่มีอัลลีลนี้ทั้งสองสำเนาจนกลายเป็น Poor Metabolizer จะพบในคนไทยประมาณร้อยละ 9 ขณะที่ชาวยุโรปพบเพียงร้อยละ 2–5 [9] ความแตกต่างนี้มีความสำคัญทางคลินิกมาก เพราะผู้ป่วยไทยที่ได้รับยา **Clopidogrel** เพื่อป้องกันลิ่มเลือดในหลอดเลือดหัวใจ มีโอกาสสูงกว่าผู้ป่วยชาวยุโรปมากที่จะไม่ได้รับประโยชน์จากยาชนิดนี้ เนื่องจากร่างกายไม่สามารถเปลี่ยนยาให้อยู่ในรูปออกฤทธิ์ได้ [9]

## 1.6 เอนไซม์ CYP450: ผู้ย่อยสลายยาในตับ

ยีนที่สำคัญที่สุดในเภสัชพันธุศาสตร์คือกลุ่มยีน **CYP450 (Cytochrome P450)** ซึ่งสร้างเอนไซม์ที่ทำหน้าที่ย่อยสลายยาและสิ่งแปลกปลอมในตับ ชื่อ CYP450 มาจากลักษณะของโปรตีนที่มีธาตุเหล็กเป็นองค์ประกอบ เมื่อจับกับก๊าซคาร์บอนมอนอกไซด์และวัดการดูดกลืนแสง จะพบค่าสูงสุดที่ความยาวคลื่น 450 นาโนเมตร จึงเป็นที่มาของชื่อนี้ เอนไซม์กลุ่ม CYP450 รับผิดชอบการเผาผลาญยาประมาณร้อยละ 70–80 ของยาทั้งหมดที่ใช้ในทางคลินิก [8]

ในบรรดาเอนไซม์ CYP450 กว่า 50 ชนิดในร่างกายมนุษย์ มีห้าตัวที่มีความสำคัญทางคลินิกสูงสุด [8] ซึ่งหนังสือเล่มนี้เรียกว่า **Big 5** ได้แก่

- **CYP2D6** อยู่บนโครโมโซมที่ 22 รับผิดชอบการย่อยยาประมาณร้อยละ 25 ของยาทั้งหมด รวมถึงยาต้านเศร้าและยาแก้ปวด
- **CYP2C19** อยู่บนโครโมโซมที่ 10 สำคัญสำหรับยาหัวใจกลุ่ม Clopidogrel และยาต้านเศร้ากลุ่ม SSRIs
- **CYP2C9** อยู่บนโครโมโซมที่ 10 เช่นกัน สำคัญสำหรับยาต้านการแข็งตัวของเลือด Warfarin และยาแก้ปวดกลุ่ม NSAIDs
- **CYP3A4 และ CYP3A5** อยู่บนโครโมโซมที่ 7 เป็นเอนไซม์ที่พบมากที่สุดในตับ และรับผิดชอบการย่อยยามากกว่าร้อยละ 40–50 ของยาทั้งหมด

รายละเอียดของ Big 5 ทั้งหมดจะอธิบายอย่างครบถ้วนในบทที่ 3

## 1.7 คลังความรู้: ฐานข้อมูลสำคัญของเภสัชพันธุศาสตร์

ปัจจุบันมีฐานข้อมูลกลางที่เปิดให้เข้าถึงได้ฟรี ทำให้นักวิจัย แพทย์ เภสัชกร และผู้สนใจทั่วไปสามารถเข้าถึงข้อมูลที่ผ่านการตรวจสอบแล้วได้โดยตรง

**PharmVar** (pharmvar.org) หรือ Pharmacogene Variation Consortium คือกลุ่มผู้เชี่ยวชาญระดับนานาชาติที่ดูแลระบบการตั้งชื่อ Star Allele และจัดเก็บข้อมูลความแปรผันของยีนที่ส่งผลต่อการตอบสนองต่อยา เป็นแหล่งอ้างอิงหลักที่ได้รับการยอมรับระดับสากลด้านเภสัชพันธุศาสตร์

**PharmGKB** (pharmgkb.org) หรือ The Pharmacogenomics Knowledge Base คือฐานข้อมูลกลางระดับโลกที่รวบรวมและวิเคราะห์ความสัมพันธ์ระหว่างความแปรผันทางพันธุกรรมกับการตอบสนองต่อยาของผู้ป่วย ได้รับการสนับสนุนจาก NIH สหรัฐอเมริกา และดูแลโดยมหาวิทยาลัยสแตนฟอร์ด

**CPIC** (cpicpgx.org) หรือ Clinical Pharmacogenetics Implementation Consortium คือกลุ่มความร่วมมือระหว่างประเทศของผู้เชี่ยวชาญด้านเภสัชพันธุศาสตร์และแพทย์ ก่อตั้งขึ้นในปี 2009 มีหน้าที่หลักคือจัดทำแนวทางปฏิบัติทางคลินิกที่บอกวิธีปรับขนาดหรือเลือกใช้ยาตามรหัสพันธุกรรมของผู้ป่วยที่ใช้ได้จริง แนวทางของ CPIC มีการจัดระดับความน่าเชื่อถือตั้งแต่ Level A ถึง Level D โดย Level A หมายถึงมีหลักฐานเพียงพอสำหรับการปรับขนาดยาหรือเปลี่ยนยาตามผลตรวจ

## สรุปท้ายบท

บทนี้วางรากฐานที่จำเป็นสำหรับการเข้าใจเภสัชพันธุศาสตร์ เราได้เรียนรู้ว่า Central Dogma อธิบายกระบวนการที่ข้อมูลใน DNA ถ่ายทอดไปยัง mRNA แล้วกลายเป็นโปรตีนและเอนไซม์ที่ย่อยสลายยา เราเข้าใจว่า SNP คือการเปลี่ยนแปลงในลำดับเบสเพียงหนึ่งตำแหน่ง ซึ่งสามารถเปลี่ยนการทำงานของเอนไซม์ได้อย่างมีนัยสำคัญ

เราได้รู้จักระบบ Star Allele ที่ PharmVar พัฒนาขึ้น และวิธีที่ Diplotype แปลงไปเป็น Activity Score และสุดท้ายเป็นฟีโนไทป์ทั้งห้าที่สำคัญ พร้อมเห็นว่าความแตกต่างของความถี่อัลลีลระหว่างชาติพันธุ์ โดยเฉพาะความถี่ CYP2C19\*2 ที่สูงในคนไทยและชาวเอเชีย ทำให้เภสัชพันธุศาสตร์มีความสำคัญเป็นพิเศษในบริบทของการแพทย์ไทย

ในบทที่ 2 เราได้เจาะลึกกระบวนการเภสัชจลนศาสตร์เพื่อทำความเข้าใจว่าหลังกลืนยาเข้าไป ร่างกายจัดการกับยาอย่างไรผ่านกระบวนการ ADME และในบทที่ 3 เราจะกลับมาเจาะลึกเอนไซม์ Big 5 แต่ละตัวอย่างละเอียด

## คำศัพท์สำคัญ

| ศัพท์ | ความหมายโดยย่อ |
|---|---|
| **Pharmacogenetics** | เภสัชพันธุศาสตร์ ศาสตร์ที่ศึกษาผลของความแตกต่างทางพันธุกรรมต่อการตอบสนองต่อยาในแต่ละบุคคล |
| **Central Dogma** | หลักการที่อธิบายการไหลของข้อมูลพันธุกรรม: DNA ถอดรหัสเป็น mRNA แล้วแปลรหัสเป็นโปรตีน |
| **SNP (Single Nucleotide Polymorphism)** | การแปรผันของลำดับ DNA ในหนึ่งตำแหน่ง เป็นรูปแบบความแตกต่างทางพันธุกรรมที่พบบ่อยที่สุดในมนุษย์ |
| **Splicing defect** | ความผิดปกติในขั้นตอนตัดต่อ mRNA ก่อนแปลเป็นโปรตีน ทำให้ได้โปรตีนที่ไม่สมบูรณ์หรือไม่ทำงาน |
| **Star Allele** | ระบบการตั้งชื่ออัลลีลของยีนที่เกี่ยวข้องกับเภสัชพันธุศาสตร์ เช่น CYP2D6\*1 หรือ CYP2D6\*4 |
| **Diplotype** | การระบุอัลลีลทั้งสองชุดที่ได้รับจากพ่อและแม่ร่วมกัน เช่น CYP2D6 \*1/\*4 |
| **Activity Score** | คะแนนรวมที่คำนวณจาก Diplotype เพื่อบ่งบอกระดับการทำงานของเอนไซม์ |
| **Poor Metabolizer (PM)** | ผู้ที่มีเอนไซม์ทำงานน้อยมากหรือไม่ทำงาน Activity Score เท่ากับ 0 |
| **Intermediate Metabolizer (IM)** | ผู้ที่เอนไซม์ทำงานได้บางส่วน Activity Score 0.25–1.0 |
| **Normal Metabolizer (NM)** | ผู้ที่เอนไซม์ทำงานได้ปกติ Activity Score 1.25–2.25 |
| **Rapid Metabolizer (RM)** | ผู้ที่เอนไซม์ทำงานดีกว่าปกติ Activity Score 2.5–3.0 |
| **Ultrarapid Metabolizer (UM)** | ผู้ที่เอนไซม์ทำงานมากผิดปกติ มักเกิดจาก Gene Duplication Activity Score ตั้งแต่ 3.0 ขึ้นไป |
| **Gene Duplication** | การมียีนตัวเดิมซ้ำกันมากกว่าหนึ่งชุดในตำแหน่งเดียวกัน ทำให้ผลิตเอนไซม์ได้มากกว่าปกติ |
| **CYP450 (Cytochrome P450)** | กลุ่มเอนไซม์ในตับที่ทำหน้าที่ย่อยสลายยาและสารแปลกปลอม รับผิดชอบการเผาผลาญยาประมาณร้อยละ 70–80 ของยาทั้งหมด |
| **PharmVar** | ฐานข้อมูลกลางที่ดูแลระบบการตั้งชื่อ Star Allele |
| **PharmGKB** | ฐานข้อมูลกลางที่รวบรวมความสัมพันธ์ระหว่างพันธุกรรมกับการตอบสนองต่อยา |
| **CPIC** | กลุ่มความร่วมมือที่จัดทำแนวทางปฏิบัติทางคลินิกด้านเภสัชพันธุศาสตร์ |

## คำถามทบทวน

1. อธิบาย Central Dogma พร้อมเชื่อมโยงให้เห็นว่ากระบวนการนี้เกี่ยวข้องกับการที่ร่างกายย่อยสลายยาอย่างไร
2. SNP คืออะไร? เหตุใด SNP เพียงหนึ่งตำแหน่งในยีน CYP2D6 จึงสามารถเปลี่ยนผลการรักษาด้วยยา Codeine ได้อย่างสิ้นเชิง?
3. หากผู้ป่วยมี Diplotype CYP2D6 \*4/\*4 จะมี Activity Score เท่าใด และถูกจัดอยู่ในฟีโนไทป์ใด ผลต่อการใช้ยา Codeine และ Tamoxifen แตกต่างกันอย่างไร?
4. เหตุใดการที่ CYP2C19\*2 พบบ่อยในคนไทยถึงร้อยละ 25–29 จึงมีความสำคัญทางคลินิกในการรักษาโรคหัวใจ?
5. PharmVar, CPIC และ PharmGKB มีบทบาทแตกต่างกันอย่างไรในการนำเภสัชพันธุศาสตร์ไปใช้จริงในทางคลินิก?

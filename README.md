
# ภาคผนวก

ภาคผนวกนี้รวบรวมตารางอ้างอิงที่ใช้ประกอบเนื้อหาบทที่ 1-13 เพื่อให้เปิดดูได้เร็วในเวชปฏิบัติและการเรียน ประกอบด้วย

- **ภาคผนวก ก** Big 5 ใน 15 วินาที (Substrate / Inhibitor / Inducer ของแต่ละ CYP)
- **ภาคผนวก ข** สรุปแนวทาง CPIC ที่เกี่ยวข้องกับเนื้อหาในเล่ม
- **ภาคผนวก ค** เกณฑ์แปลผลฟีโนไทป์รายยีน และความถี่ในคนไทย
- **ภาคผนวก ง** คำศัพท์สำคัญ เรียงตามลำดับตัวอักษร A-Z
- **ภาคผนวก จ** แหล่งข้อมูลที่แนะนำ และวิธีใช้

> **ข้อควรระวัง:** ตารางในภาคผนวกนี้เป็นเครื่องมือช่วยจำและช่วยเรียนรู้ ไม่ใช่คำสั่งการรักษา ระดับหลักฐาน คำแนะนำ และรายชื่อยาที่เป็น inhibitor/inducer มีการปรับปรุงอยู่เสมอ ควรยืนยันกับ cpicpgx.org และตาราง Flockhart ฉบับล่าสุดก่อนนำไปใช้กับผู้ป่วยจริง

## วิธีอ่านตารางนี้

- **Substrate** คือยาที่ถูกเอนไซม์นั้นเผาผลาญ ยาที่เป็น **Prodrug** ทำเครื่องหมาย (P) เพราะผลของฟีโนไทป์จะกลับทิศเมื่อเทียบกับ Active Drug (บทที่ 5 และ 8)
- **Inhibitor** ทำให้ substrate สูงขึ้น และเสี่ยงเกิด **Phenoconversion** ไปทาง Poor Metabolizer (บทที่ 3 และ 10)
- **Inducer** ทำให้ substrate ต่ำลง และเสี่ยงเกิด Phenoconversion ไปทาง Rapid/Ultrarapid
- ถ้า substrate เป็น Prodrug ผลของ inhibitor/inducer จะกลับทิศ (inhibitor ทำให้ยาไม่ได้ผล)
- ระดับความแรงของ inhibitor/inducer (strong / moderate / weak) อ้างอิงขนาดการเปลี่ยนแปลงของพื้นที่ใต้กราฟความเข้มข้นยา (AUC) ตามที่อธิบายในบทที่ 10

## ก.1 CYP2D6: เอนไซม์ที่หลากหลายที่สุด

| หัวข้อ | รายละเอียด |
|---|---|
| ส่วนแบ่งการเผาผลาญยา | ประมาณ 25% ของยาที่ใช้ทางคลินิก |
| โครโมโซม | 22 |
| จุดเด่น | Star Allele มากกว่า 100 แบบ มี gene deletion (\*5) และ gene duplication (\*1xN) |
| ในคนไทย/เอเชีย | \*10 (ทำงานลดลง) พบสูงราว 40% ทำให้ผู้ป่วยไทยจำนวนมากเป็น IM; \*4 พบน้อยมาก (<1%); \*1xN พบราว 1-2% |
| ระวังเป็นพิเศษ | Codeine, Tramadol, Tamoxifen (Prodrug) |

**Substrate**

| กลุ่มยา | ตัวอย่าง |
|---|---|
| ยาแก้ปวดกลุ่มโอปิออยด์ | Codeine (P), Tramadol (P), Hydrocodone, Oxycodone |
| ยามะเร็งเต้านม | Tamoxifen (P: เปลี่ยนเป็น Endoxifen) |
| ยาต้านเศร้า | Amitriptyline, Nortriptyline, Paroxetine, Venlafaxine |
| ยาจิตเวช | Risperidone, Haloperidol, Aripiprazole |
| ยาหัวใจ | Metoprolol, Carvedilol |
| ยาอื่น | Ondansetron, Atomoxetine |

**Inhibitor**

| ความแรง | ตัวอย่าง |
|---|---|
| Strong | Fluoxetine, Paroxetine, Bupropion, Quinidine, Terbinafine |
| Moderate | Duloxetine, Cinacalcet |
| Weak | Amiodarone, Sertraline (ขนาดสูง) |

**Inducer:** ไม่มีตัวที่สำคัญทางคลินิก

**ข้อควรจำ**
1. Fluoxetine และ Paroxetine ทำให้ NM กลายเป็น PM ได้ (Phenoconversion) และเป็น mechanism-based inhibitor ผลอาจอยู่นานหลังหยุดยา
2. Tamoxifen + Fluoxetine/Paroxetine/Bupropion ทำให้ระดับ Endoxifen ลดลง (บทที่ 5)
3. UM ที่ได้ inhibitor แรงอาจกลับกลายเป็นคล้าย PM ตามกรณีศึกษาในบทที่ 10

## ก.2 CYP2C19: ยีนที่คนไทยต้องโฟกัส

| หัวข้อ | รายละเอียด |
|---|---|
| ส่วนแบ่งการเผาผลาญยา | ประมาณ 15% |
| โครโมโซม | 10 |
| จุดเด่น | แปลผลด้วยการจับคู่ function ของอัลลีล มีกลุ่ม RM (\*1/\*17) และ UM (\*17/\*17) |
| ในคนไทย | \*2 ราว 25-29%, \*3 ราว 2.5%, \*17 ราว 1.8%; PM ราว 9%; IM ราว 30-35% |
| ระวังเป็นพิเศษ | Clopidogrel (P), SSRIs, PPIs |

**Substrate**

| กลุ่มยา | ตัวอย่าง |
|---|---|
| ยาต้านเกล็ดเลือด | Clopidogrel (P) |
| ยาลดกรด (PPIs) | Omeprazole, Esomeprazole, Lansoprazole, Pantoprazole |
| ยาต้านเศร้า | Citalopram, Escitalopram, Sertraline, Amitriptyline |
| ยาต้านเชื้อรา | Voriconazole |
| ยาอื่น | Diazepam, Clobazam |

**Inhibitor**

| ความแรง | ตัวอย่าง |
|---|---|
| Strong | Fluvoxamine, Fluconazole, Ticlopidine |
| Moderate/Weak | Omeprazole, Esomeprazole, Fluoxetine |

**Inducer:** Rifampicin, Carbamazepine, Phenytoin, St John's wort, Efavirenz

**ข้อควรจำ**
1. Clopidogrel ต้องใช้ CYP2C19 ทั้งสองขั้นตอนการกระตุ้น (บทที่ 5) PM/IM ได้ประโยชน์น้อยลง แนะนำเปลี่ยนเป็น Prasugrel หรือ Ticagrelor
2. PPI ในกลุ่ม UM (\*17/\*17) อาจควบคุมกรดไม่พอที่ขนาดมาตรฐาน (เคสคุณมานะ บทที่ 4)
3. SSRIs ซึ่งเป็น Active Drug: PM มีระดับยาสูง UM มีระดับยาต่ำ ตรงข้ามกับ Prodrug (บทที่ 8)
4. Omeprazole เป็นทั้ง substrate และ inhibitor ของ CYP2C19 ระวังเมื่อใช้ร่วมกับ Clopidogrel

## ก.3 CYP2C9: ยาช่วงการรักษาแคบ

| หัวข้อ | รายละเอียด |
|---|---|
| ส่วนแบ่งการเผาผลาญยา | ประมาณ 15% |
| โครโมโซม | 10 |
| จุดเด่น | เกี่ยวข้องกับยา Narrow Therapeutic Index |
| อัลลีลสำคัญ | \*2 (ทำงานลดลง), \*3 (ทำงานลดลงมาก/แทบไม่ทำงาน) |
| ระวังเป็นพิเศษ | Warfarin (ร่วมกับ VKORC1), Phenytoin |

**Substrate**

| กลุ่มยา | ตัวอย่าง |
|---|---|
| ยาต้านการแข็งตัวของเลือด | Warfarin (S-warfarin) |
| ยากันชัก | Phenytoin |
| ยากลุ่ม NSAIDs | Celecoxib, Ibuprofen, Diclofenac, Meloxicam, Piroxicam |
| ยาลดความดัน | Losartan (P บางส่วน) |
| ยาเบาหวานกลุ่ม Sulfonylureas | Glipizide, Glimepiride, Glibenclamide |

**Inhibitor:** Fluconazole, Miconazole, Amiodarone, Sulfamethoxazole (ใน Cotrimoxazole), Metronidazole

**Inducer:** Rifampicin, Carbamazepine, Phenobarbital

**ข้อควรจำ**
1. Warfarin ต้องพิจารณา CYP2C9 (ฝั่งเภสัชจลนศาสตร์) ร่วมกับ VKORC1 (ฝั่งเภสัชพลศาสตร์) เสมอ (บทที่ 3 และ 7)
2. Fluconazole, Amiodarone, Cotrimoxazole เป็นยาที่พบบ่อยในโรงพยาบาลและเพิ่มระดับ Warfarin ได้มาก ต้องติดตาม INR ถี่ขึ้น
3. Phenytoin มีช่วงการรักษาแคบ ควรติดตามระดับยาในเลือดเมื่อมี inhibitor/inducer

## ก.4 CYP3A4: ยักษ์ใหญ่ของตับและลำไส้

| หัวข้อ | รายละเอียด |
|---|---|
| ส่วนแบ่งการเผาผลาญยา | ประมาณ 40-50% |
| โครโมโซม | 7 |
| จุดเด่น | ความแปรปรวนทางพันธุกรรมน้อย แต่ **ปฏิกิริยายากับยา (DDI) และอาหาร** มีผลมาก |
| ในบริบทไทย | ส้มโอ (Pomelo) มี Furanocoumarins ยับยั้ง CYP3A4 ที่ลำไส้ได้ 1-3 วัน |
| ระวังเป็นพิเศษ | Tacrolimus, Statins, Midazolam |

**Substrate**

| กลุ่มยา | ตัวอย่าง |
|---|---|
| ยากดภูมิคุ้มกัน | Tacrolimus, Cyclosporine, Sirolimus |
| ยาลดไขมัน | Simvastatin, Atorvastatin, Lovastatin |
| ยาลดความดัน | Amlodipine, Nifedipine |
| ยากลุ่ม Benzodiazepines | Midazolam, Alprazolam |
| ยาแก้ปวดโอปิออยด์ | Fentanyl, Oxycodone |
| ยามะเร็ง | Venetoclax |
| ยาอื่น | Sildenafil, Ticagrelor |

**Inhibitor**

| ความแรง | ตัวอย่าง |
|---|---|
| Strong | Clarithromycin, Ketoconazole, Itraconazole, Voriconazole, Ritonavir, Cobicistat |
| Moderate | Diltiazem, Verapamil, Erythromycin, Fluconazole |
| อาหาร | ส้มโอ น้ำเกรปฟรุต |

**Inducer:** Rifampicin, Carbamazepine, Phenytoin, Phenobarbital, St John's wort, Efavirenz

**ข้อควรจำ**
1. Clarithromycin เป็น mechanism-based inhibitor ผลอยู่นานกว่าครึ่งชีวิตของยา (บทที่ 10)
2. Statin + ส้มโอ/inhibitor แรง เสี่ยงกล้ามเนื้อสลายตัว (Rhabdomyolysis)
3. Rifampicin + Tacrolimus ทำให้ระดับ Tacrolimus ตกเร็ว เสี่ยงปฏิเสธอวัยวะปลูกถ่าย (บทที่ 3)

## ก.5 CYP3A5: คู่ต่างตามเชื้อชาติ

| หัวข้อ | รายละเอียด |
|---|---|
| บทบาท | ทำงานร่วมกับ CYP3A4 ใน substrate ที่ทับซ้อนกัน |
| โครโมโซม | 7 |
| จุดเด่น | บางคนสร้างเอนไซม์ได้ (Expresser) บางคนสร้างไม่ได้ (Non-expresser) ตามอัลลีล \*3 |
| ในคนไทย | Expresser ราว 30%, Non-expresser ราว 70% (ชาวยุโรปเป็น Non-expresser เกือบ 90%) |
| ระวังเป็นพิเศษ | Tacrolimus ในผู้ป่วยปลูกถ่ายอวัยวะ |

**Substrate:** Tacrolimus เป็นยาหลัก และ substrate อื่นที่ทับซ้อนกับ CYP3A4 เช่น Midazolam

**Inhibitor / Inducer:** ใช้ร่วมกับ CYP3A4 ตามตาราง ก.4

**ข้อควรจำ**
1. Expresser กำจัด Tacrolimus เร็ว CPIC แนะนำขนาดเริ่มต้นสูงขึ้นประมาณ 1.5-2 เท่า และติดตามระดับยาถี่ (บทที่ 3)
2. ผลของ inhibitor/inducer ของ CYP3A4 ยังใช้ได้กับผู้ป่วยกลุ่มนี้เสมอ

## ก.6 ตารางเปรียบเทียบรวม (สำหรับพิมพ์ 1 หน้า)

| CYP | ส่วนแบ่ง | Prodrug สำคัญ | Active drug สำคัญ | Inhibitor แรง | Inducer สำคัญ |
|---|---|---|---|---|---|
| 2D6 | ~25% | Codeine, Tramadol, Tamoxifen | TCAs, Metoprolol, Risperidone | Fluoxetine, Paroxetine, Bupropion | ไม่มี |
| 2C19 | ~15% | Clopidogrel | SSRIs, PPIs, Voriconazole | Fluvoxamine, Fluconazole | Rifampicin, Carbamazepine |
| 2C9 | ~15% | Losartan (บางส่วน) | Warfarin, Phenytoin, NSAIDs | Fluconazole, Amiodarone | Rifampicin, Carbamazepine |
| 3A4 | ~40-50% | ไม่ใช่จุดเด่น | Tacrolimus, Statins, Amlodipine | Clarithromycin, Azoles, Ritonavir, ส้มโอ | Rifampicin, Carbamazepine, St John's wort |
| 3A5 | ร่วมกับ 3A4 | ไม่ใช่จุดเด่น | Tacrolimus | ร่วมกับ 3A4 | ร่วมกับ 3A4 |

# ภาคผนวก ข: สรุปแนวทาง CPIC ที่เกี่ยวข้องกับเนื้อหาในเล่ม

## ข.1 ความหมายของระดับ CPIC

- **Level A**: มีหลักฐานเพียงพอที่จะปรับการใช้ยาตามผลตรวจยีน และมีคำแนะนำระดับ moderate หรือ strong อย่างน้อยหนึ่งข้อ
- **Level B**: หลักฐานอ่อนกว่า แต่ไม่ขัดแย้ง คำแนะนำระดับ optional
- **Level C**: มีหลักฐานบ้าง แต่ยังไม่มีคำแนะนำเชิงปฏิบัติชัดเจน
- ระดับ A/B/C **ไม่ใช่** ระบบเดียวกับ Level of Evidence หรือ Strength of Recommendation ของแต่ละคำแนะนำ (บทที่ 6)

## ข.2 ยาที่ต้องพึ่งพา CYP2D6

| ยา | ฟีโนไทป์ | สรุปคำแนะนำ | บท |
|---|---|---|---|
| **Codeine** | PM | ไม่แนะนำ เพราะไม่เปลี่ยนเป็น Morphine ยาไม่ได้ผล เปลี่ยนเป็นยาแก้ปวดที่ไม่ผ่าน CYP2D6 | 4, 5, 8 |
| | IM | อาจแก้ปวดได้น้อยกว่าที่คาด พิจารณาเปลี่ยนยาหรือติดตามอย่างระมัดระวัง | 5 |
| | NM / RM | ใช้ขนาดปกติได้ | 5 |
| | UM | **ห้ามใช้** เสี่ยง Morphine toxicity และกดการหายใจ | 1, 5, 8 |
| **Tramadol** | PM | ผลแก้ปวดลดลงมาก ระมัดระวัง พิจารณายาอื่น | 5, 8 |
| | UM | เสี่ยงกดการหายใจและ Serotonin syndrome หลีกเลี่ยง | 5, 8 |
| **Tamoxifen** | PM / IM (รวม \*10/\*10) | พิจารณา 40 mg/วัน หรือเปลี่ยนเป็น Aromatase Inhibitor (เฉพาะวัยหมดประจำเดือน) | 5 |
| | NM / UM | 20 mg/วัน ตามปกติ | 5 |
| **TCAs, Metoprolol** | PM / IM | ระดับยาอาจสูง พิจารณาลดขนาดและติดตามผลข้างเคียง | 3, 7 |

**ข้อห้ามและคำเตือนจาก FDA (ไม่ขึ้นกับผลตรวจยีน)**
- Codeine และ Tramadol ห้ามใช้ในเด็กอายุต่ำกว่า 12 ปี
- ห้ามใช้ Codeine หลังผ่าตัดต่อมทอนซิลหรืออะดีนอยด์ในเด็ก
- ไม่แนะนำในมารดาที่ให้นมบุตร (บทที่ 8)

## ข.3 ยาที่ต้องพึ่งพา CYP2C19

| ยา | ฟีโนไทป์ | สรุปคำแนะนำ | บท |
|---|---|---|---|
| **Clopidogrel** (ACS/PCI) | PM | **ห้ามใช้** เปลี่ยนเป็น Prasugrel หรือ Ticagrelor | 5, 6, 7 |
| | IM | หลีกเลี่ยงอย่างหนักแน่น เปลี่ยนเป็น Prasugrel หรือ Ticagrelor (ฉบับปี 2022) | 5, 6, 7 |
| | NM / RM / UM | ขนาดปกติ | 5, 7 |
| **SSRIs** (Citalopram, Escitalopram, Sertraline) | PM | พิจารณาลดขนาดเริ่มต้นและคงระดับราว 50% หรือไทเทรตช้า | 8 |
| | UM | ข้อมูลไม่พอกำหนดขนาด พิจารณายาทางเลือกที่ไม่ผ่าน CYP2C19 | 8 |
| **PPIs** (Omeprazole ฯลฯ) | UM | ระดับยาอาจต่ำ ควบคุมกรดไม่พอ พิจารณาปรับขนาดและติดตามผล | 4 |
| | PM | ระดับยาสูงขึ้น พิจารณาทบทวนขนาดยาในการใช้ระยะยาว | 3 |
| **Voriconazole** | PM | ระดับยาสูง เสี่ยงพิษ | 3 |
| | UM | ระดับยาต่ำ เสี่ยงรักษาไม่ได้ผล ควรพิจารณายาอื่นหรือติดตามระดับยา | 3 |

## ข.4 ยาที่ต้องพึ่งพา CYP2C9 และ VKORC1

| ยา | ยีน | สรุปคำแนะนำ | บท |
|---|---|---|---|
| **Warfarin** | CYP2C9 + VKORC1 | คำนวณขนาดเริ่มต้นจากสองยีนร่วมกัน (ตาราง 7.5) ผู้ที่เป็น PM ร่วมกับ VKORC1 ไวสูงอาจต้องการยาน้อยกว่าขนาดมาตรฐานหลายเท่า ติดตาม INR ถี่ | 3, 7 |
| **Phenytoin** | CYP2C9 (+ HLA-B\*15:02) | IM/PM: ลดขนาดคงระดับและติดตามระดับยา และหลีกเลี่ยงถ้า HLA-B\*15:02 บวก | 3, 9 |

1. CPIC ไม่ใช่หน่วยงานอนุมัติยา เป็นเพียงคำแนะนำการแปลผลตรวจยีน (บทที่ 6)

3. ข้อมูลประชากรไทยและเอเชียตะวันออกเฉียงใต้ยังจำกัดในบางยีน
4. แนวทางอิงจีโนไทป์เป็นหลัก ไม่ครอบคลุม Phenoconversion เต็มที่ (บทที่ 10)
5. แนวทางมีการปรับปรุงเป็นระยะ (ตัวอย่างคือ CYP2C19-Clopidogrel ฉบับ 2011, 2013, 2022)

# ภาคผนวก ค: เกณฑ์แปลผลฟีโนไทป์รายยีน และความถี่ในคนไทย

## ค.1 หลักการ: เกณฑ์เป็นแบบเฉพาะยีน

เกณฑ์แปลผลฟีโนไทป์ **ต้องใช้ตามยีนเท่านั้น** ห้ามนำเกณฑ์ของยีนหนึ่งไปใช้กับอีกยีนหนึ่ง (บทที่ 4) และหมายเลขดาวของยีนหนึ่งไม่เทียบกับอีกยีนหนึ่ง เช่น CYP2D6\*17 กับ CYP2C19\*17 เป็นคนละอัลลีลโดยสิ้นเชิง

## ค.2 CYP2D6 (ใช้ Activity Score)

# ภาคผนวก จ: แหล่งข้อมูลที่แนะนำ

## จ.1 ฐานข้อมูลหลัก

| แหล่งข้อมูล | เว็บไซต์ | ใช้ทำอะไร |
|---|---|---|
| **PharmVar** | pharmvar.org | ตรวจชื่อและนิยามของ Star Allele ยืนยันการตั้งชื่ออัลลีลที่พบในรายงานผลตรวจ |
| **PharmGKB** | pharmgkb.org | ค้นความสัมพันธ์ยีน-ยา คำอธิบายบนฉลากยา และตาราง Activity Value ของอัลลีล |
| **CPIC** | cpicpgx.org | อ่านแนวทางฉบับเต็ม ตารางแปลผล diplotype เป็นฟีโนไทป์ และตารางความถี่อัลลีลตามประชากร |
| **Flockhart Table** | drug-interactions.medicine.iu.edu | ตรวจว่ายาใดเป็น substrate, inhibitor หรือ inducer ของ CYP450 |
| **FDA Table of Pharmacogenomic Biomarkers in Drug Labeling** | fda.gov (ค้นชื่อตาราง) | ดูข้อมูลเภสัชพันธุศาสตร์ที่ระบุบนฉลากยาที่ FDA รับรอง |

## จ.2 วิธีใช้อย่างเป็นขั้นตอน

**กรณีมีผลตรวจยีนอยู่ในมือ**
1. อ่าน diplotype จากรายงาน (เช่น CYP2C19 \*1/\*2)
2. ตรวจนิยามอัลลีลที่ PharmVar/PharmGKB ว่ามีหน้าที่ระดับใด
3. แปลเป็นฟีโนไทป์ด้วยตารางของ CPIC สำหรับยีนนั้น (ดูภาคผนวก ค เป็นตัวช่วยเบื้องต้น)
4. เปิดแนวทาง CPIC ของยาที่เกี่ยวข้อง อ่านคำแนะนำตามฟีโนไทป์และระดับความเข้มข้นของคำแนะนำ
5. ตรวจรายการยาทั้งหมดของผู้ป่วยด้วยตาราง Flockhart เพื่อหา Phenoconversion (ภาคผนวก ก)
6. พิจารณาอายุ การทำงานของตับและไต โรคร่วม ก่อนตัดสินใจ

**กรณีต้องการตรวจซ้ำก่อนสั่งยา**
- ทบทวนผลตรวจกับรายการยาปัจจุบันทุกครั้งที่มีการเปลี่ยนแปลงยา เพราะฟีโนไทป์ที่แท้จริงเปลี่ยนได้ตลอดเวลา (บทที่ 10)

## จ.3 สัญญาณที่ควรพิจารณาส่งตรวจยีน (สรุปจากบทที่ 3 และ 7)

| สถานการณ์ | ยีนที่ควรพิจารณา |
|---|---|
| กิน Clopidogrel ตรงเวลาแต่ยังเกิดลิ่มเลือดอุดตันซ้ำ | CYP2C19 |
| ผู้ป่วยไทยที่จะทำหัตถการขยายหลอดเลือดหัวใจ | CYP2C19 (ตรวจล่วงหน้า) |
| ควบคุม INR จาก Warfarin ไม่ได้ หรือต้องการขนาดต่างจากคนอื่นมาก | CYP2C9 + VKORC1 |
| กิน Simvastatin แล้วปวดกล้ามเนื้อรุนแรงผิดปกติ | SLCO1B1 |
| ใช้ Codeine/Tramadol แล้วไม่หายปวด หรือง่วงซึมหายใจช้า | CYP2D6 |
| ก่อนเริ่ม Carbamazepine | HLA-B\*15:02 |
| ก่อนเริ่ม Allopurinol | HLA-B\*58:01 |
| ก่อนเริ่ม Abacavir | HLA-B\*57:01 |
| ผู้ป่วยปลูกถ่ายอวัยวะที่จะเริ่ม Tacrolimus | CYP3A5 |

## จ.4 แหล่งอ้างอิงภาษาไทยและงานวิจัยในประเทศ

- งานวิจัยของกลุ่มเภสัชพันธุศาสตร์ คณะแพทยศาสตร์โรงพยาบาลรามาธิบดี มหาวิทยาลัยมหิดล ซึ่งเป็นแหล่งข้อมูลความถี่อัลลีลและการนำ HLA-B\*15:02 เป็น Standard of Care ที่อ้างอิงในบทที่ 1, 3, 9 (เช่น Sukasem และคณะ)
- Sukprasong R และคณะ (Sci Rep 2021) ความถี่อัลลีล CYP2C9, CYP2C19, CYP3A4 ในประชากรไทย (บทที่ 12)
- Hongkaew Y และคณะ (Sci Rep 2021) CYP2D6 Activity Score ในเด็กไทยที่ได้รับ Risperidone (บทที่ 1, 12)

## จ.5 หลักการใช้ภาคผนวกนี้อย่างปลอดภัย

1. ตารางในภาคผนวกเป็นตัวช่วยจำ ไม่แทนที่แนวทางฉบับเต็ม
2. ผลตรวจยีนเป็นเพียงหนึ่งในปัจจัย ต้องประกอบกับยาที่ใช้ร่วมกัน อายุ อวัยวะทำงาน และโรคร่วม
3. ผลตรวจที่เป็น "ปกติ" ไม่ได้รับประกันว่าไม่มีความเสี่ยง (บทที่ 3, 9, 13)
4. เมื่อข้อมูลในหนังสือกับแหล่งข้อมูลล่าสุดต่างกัน ให้ยึดแหล่งข้อมูลล่าสุด

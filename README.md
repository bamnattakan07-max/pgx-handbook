# บทที่ 13: อนาคตของเภสัชพันธุศาสตร์ — ตรวจครั้งเดียว ใช้ได้ตลอดชีวิต

## วัตถุประสงค์การเรียนรู้

หลังจากอ่านบทนี้จบ ผู้อ่านจะสามารถ:
1. อธิบายความแตกต่างระหว่างแนวคิด Reactive PGx และ Preemptive PGx และข้อดีของการตรวจยีนล่วงหน้า
2. ยกตัวอย่างหลักฐานเชิงประจักษ์ที่สนับสนุนว่า Preemptive PGx ช่วยลดผลข้างเคียงจากยาได้จริง ทั้งในบริบทยุโรปและเอเชีย
3. อธิบายแนวโน้มการลดลงของราคาการตรวจยีน และวิเคราะห์ความคุ้มค่าทางเศรษฐศาสตร์สาธารณสุขของ Preemptive PGx
4. อธิบายบทบาทของ Multi-Gene Panel และการบูรณาการข้อมูล PGx เข้ากับระบบเวชระเบียนอิเล็กทรอนิกส์ (EHR)
5. วิเคราะห์ประเด็นทางจริยธรรมที่เกี่ยวข้องกับเภสัชพันธุศาสตร์ ทั้งด้านความเป็นส่วนตัวของข้อมูลพันธุกรรมและความเท่าเทียมในการเข้าถึง

ย้อนกลับไปในปี 2003 โครงการ Human Genome Project ใช้เวลาถึง 13 ปีและงบประมาณกว่า 3,000 ล้านเหรียญสหรัฐ หรือประมาณ 100,000 ล้านบาท เพื่อถอดรหัสจีโนมมนุษย์เป็นครั้งแรกในประวัติศาสตร์ แต่มาถึงปี 2024 เพียงแค่ส่งตัวอย่าง DNA ไปตรวจ ก็สามารถได้รับผล Multi-gene PGx Panel ที่บอกว่าร่างกายตอบสนองต่อยาหลักกว่า 50 ชนิดอย่างไร ในราคาเพียง 3,000 ถึง 10,000 บาท และรอผลเพียง 2 ถึง 3 สัปดาห์เท่านั้น

การเปลี่ยนแปลงครั้งนี้ไม่ได้เป็นเพียงเรื่องของราคาที่ลดลงเท่านั้น แต่เป็นการเปลี่ยนแนวคิดทั้งระบบของการแพทย์ จากแนวคิด "ยาสำหรับทุกคน" ไปสู่แนวคิด "ยาสำหรับคุณโดยเฉพาะ" บทสุดท้ายนี้จะพาไปสำรวจว่าเภสัชพันธุศาสตร์กำลังก้าวไปสู่อนาคตอย่างไร ทั้งในแง่ของแนวคิดการตรวจยีน เทคโนโลยี ประเด็นจริยธรรม และทิศทางที่จะเกิดขึ้นในอีก 10 ปีข้างหน้า

## 13.1 Reactive PGx และ Preemptive PGx: เปลี่ยนวิธีคิดทั้งระบบ

แนวทางดั้งเดิมของการใช้เภสัชพันธุศาสตร์ในทางคลินิกเรียกว่า **Reactive PGx** คือการรักษาไปก่อนแล้วค่อยตรวจยีนภายหลังเมื่อเกิดปัญหาขึ้นแล้ว ดังเส้นทางต่อไปนี้

```
ผู้ป่วยต้องการยา X
    │
    ▼
แพทย์สั่งยา X ในขนาดมาตรฐาน
    │
    ▼
ผู้ป่วยมีผลข้างเคียง หรือยาไม่ได้ผล
    │
    ▼
ค่อยส่งตรวจยีน (รอ 1–2 สัปดาห์)
    │
    ▼
เปลี่ยนยาหรือปรับขนาด — แต่ผู้ป่วยได้รับอันตรายไปแล้ว
```

จะเห็นได้ว่าข้อจำกัดสำคัญของแนวทางนี้คือ ผู้ป่วยต้องประสบปัญหาก่อนแล้วจึงจะได้รับการแก้ไข ซึ่งในกรณีของยาที่มีความเสี่ยงรุนแรง เช่น Codeine หรือ Carbamazepine ความล่าช้านี้อาจหมายถึงอันตรายที่แก้ไขไม่ได้แล้ว แนวทางใหม่ที่กำลังได้รับความสนใจมากขึ้นเรื่อย ๆ คือ **Preemptive PGx** ซึ่งกลับลำดับขั้นตอน คือตรวจยีนก่อนแล้วจึงเริ่มการรักษา ดังเส้นทางต่อไปนี้

```
ตรวจยีนครั้งเดียวตั้งแต่ต้น (หรือตั้งแต่เด็ก)
    │
    ▼
เก็บผลไว้ใน Electronic Health Record (EHR)
    │
    ▼
เมื่อใดก็ตามที่แพทย์สั่งยาที่เกี่ยวข้อง
    │
    ▼
ระบบแจ้งเตือนอัตโนมัติ "ผู้ป่วยคนนี้มีผลยีน..."
    │
    ▼
แพทย์เลือกยาและขนาดที่เหมาะสมตั้งแต่แรก
```

ข้อดีหลักของ Preemptive PGx คือไม่ต้องรอผลตรวจเมื่อจำเป็นต้องใช้ยาอย่างเร่งด่วน สามารถครอบคลุมยีนหลายตัวได้ในการตรวจครั้งเดียว และเนื่องจากยีนของแต่ละคนไม่เปลี่ยนแปลงไปตามกาลเวลา การตรวจเพียงครั้งเดียวจึงสามารถใช้ประโยชน์ได้ตลอดชีวิต

## 13.2 หลักฐานว่า Preemptive PGx ได้ผลจริง

การศึกษาที่ชื่อว่า PREPARE ซึ่งดำเนินการใน 7 ประเทศยุโรป ได้ศึกษาผู้ป่วยจำนวน 6,944 คน และพบว่าการตรวจ Preemptive PGx สามารถลดการเกิดผลข้างเคียงจากยาที่มีนัยสำคัญทางคลินิกได้ถึงร้อยละ 30 [1] กล่าวอีกนัยหนึ่งคือ หากมีการตรวจยีนล่วงหน้า ผู้ป่วยประมาณ 3 ใน 10 คนที่จะเกิดผลข้างเคียงรุนแรงสามารถได้รับการป้องกันล่วงหน้าได้

ในบริบทของเอเชีย การศึกษาในประเทศสิงคโปร์ระหว่างปี 2022 ถึง 2023 ได้ทดลองตรวจยีน 5 ตัว ได้แก่ CYP2D6, CYP2C9, CYP2C19, SLCO1B1 และ HLA-B\*58:01 สำหรับยา 29 ชนิด ในผู้ป่วย 500 คน จาก 5 คลินิก และพบว่า Preemptive PGx สามารถนำไปใช้ได้จริงในบริบททางคลินิกของเอเชีย โดยแพทย์ส่วนใหญ่มีความพึงพอใจกับระบบนี้ [2]

สำหรับประเทศไทย สถานการณ์ปัจจุบันสามารถสรุปได้ดังตารางที่ 13.1

| สิ่งที่ทำแล้ว | สิ่งที่กำลังพัฒนา |
|---|---|
| HLA-B\*15:02 → Carbamazepine (เป็น Standard of Care แล้ว) | Multi-gene Panel ในโรงพยาบาลมหาวิทยาลัย |
| HLA-B\*58:01 → Allopurinol (หลายโรงพยาบาลเริ่มใช้แล้ว) | การบูรณาการกับ EHR แบบเต็มรูปแบบ |
| CYP2C19 → Clopidogrel (บางโรงพยาบาล) | ข้อมูลความถี่ยีนในคนไทยที่ครอบคลุมมากขึ้น |

## 13.3 ราคาที่กำลังลดลงอย่างรวดเร็ว

ราคาการตรวจ Whole Genome Sequencing ลดลงอย่างก้าวกระโดดในช่วง 20 ปีที่ผ่านมา ดังแสดงในตารางที่ 13.2

| ปี | ค่าใช้จ่ายโดยประมาณ |
|---|---|
| 2003 (Human Genome Project) | ~3,000,000,000 บาท |
| 2010 | ~30,000,000 บาท |
| 2015 | ~30,000 บาท |
| 2020 | ~3,000 บาท |
| 2024 | ~1,500–3,000 บาท |

ส่วนการตรวจ PGx Panel เฉพาะยีนที่สำคัญทางคลินิก ในปี 2024 มีราคาอยู่ที่ประมาณ 3,000 ถึง 10,000 บาท ขึ้นอยู่กับจำนวนยีนที่ตรวจ เมื่อประเมินความคุ้มค่าในเชิงเศรษฐศาสตร์สาธารณสุขแล้ว หากการตรวจยีนราคา 5,000 บาทสามารถช่วยป้องกันการเกิด SJS จาก Carbamazepine ซึ่งต้องรักษาตัวในโรงพยาบาลนานถึง 3 ถึง 6 สัปดาห์ ค่าใช้จ่ายในการรักษาที่หลีกเลี่ยงได้อาจสูงถึง 500,000 ถึง 2,000,000 บาท โดยยังไม่นับรวมความเจ็บปวดและความเสี่ยงต่อการเสียชีวิตของผู้ป่วย

## 13.4 Multi-Gene Panel Testing: ตรวจครั้งเดียวได้ทุกอย่าง

แผง PGx มาตรฐานสากลที่ใช้กันในปัจจุบันมักรวมยีนสำคัญหลายตัวไว้ในการตรวจครั้งเดียว ดังสรุปในตารางที่ 13.3

| ยีน | ยาสำคัญ | CPIC Level |
|---|---|---|
| CYP2D6 | Codeine, Tamoxifen, TCAs, SSRIs | A |
| CYP2C19 | Clopidogrel, SSRIs, PPIs | A |
| CYP2C9 | Warfarin, NSAIDs, Phenytoin | A |
| CYP3A5 | Tacrolimus | A |
| SLCO1B1 | Statins | A |
| ABCG2 | Rosuvastatin | A |
| VKORC1 | Warfarin | A |
| HLA-B\*57:01 | Abacavir | A |
| HLA-B\*15:02 | Carbamazepine | A |
| TPMT/NUDT15 | Azathioprine, 6-MP (ยามะเร็ง) | A |
| DPYD | Fluorouracil (ยาเคมีบำบัด) | A |

จะเห็นได้ว่ายีนทั้งหมดในตารางนี้ได้รับการจัดระดับหลักฐานสูงสุดคือ CPIC Level A ครอบคลุมยาตั้งแต่ยาแก้ปวด ยาต้านซึมเศร้า ยาป้องกันการปฏิเสธอวัยวะ ไปจนถึงยาเคมีบำบัด ซึ่งสะท้อนให้เห็นว่าการตรวจครั้งเดียวสามารถให้ข้อมูลที่เป็นประโยชน์ต่อการสั่งจ่ายยาได้หลากหลายกลุ่มมาก

## 13.5 EHR Integration: เมื่อข้อมูลยีนเข้าไปอยู่ในระบบโรงพยาบาล

ข้อมูล PGx จะไม่เกิดประโยชน์เลยหากไม่สามารถนำไปใช้ได้ทันทีในขณะที่แพทย์กำลังสั่งยา จุดสำคัญที่สุดจึงอยู่ที่การบูรณาการข้อมูลนี้เข้ากับระบบเวชระเบียนอิเล็กทรอนิกส์ หรือ EHR [3] ดังตัวอย่างเส้นทางการทำงานต่อไปนี้

```
แพทย์กำลังสั่ง Codeine ให้เด็กอายุ 8 ขวบ
           │
           ▼
ระบบ EHR ตรวจสอบ PGx record ของผู้ป่วย
           │
    ┌──────┴──────┐
    │              │
ไม่พบข้อมูล     พบผล CYP2D6 UM
    │              │
แนะนำให้ตรวจ    Alert สีแดงปรากฏ:
                "ผู้ป่วยเป็น CYP2D6 UM
                Codeine ห้ามใช้ เสี่ยงพิษ
                พิจารณา Morphine แทน"
                [ดูรายละเอียด CPIC]  [ยืนยัน]
```

อย่างไรก็ตาม การนำระบบนี้ไปใช้จริงในวงกว้างยังมีความท้าทายหลายประการ ดังสรุปในตารางที่ 13.4

| ความท้าทาย | แนวทางแก้ไข |
|---|---|
| แพทย์ไม่คุ้นเคยกับ PGx | จัดอบรมให้ความรู้ และออกแบบ CDS ที่ใช้งานง่าย |
| Alert Fatigue (การแจ้งเตือนมากเกินไปจนถูกมองข้าม) | เลือกแสดงเฉพาะการแจ้งเตือนที่นำไปปฏิบัติได้จริง |
| ข้อมูลไม่ครบถ้วน | ใช้ Multi-gene panel แทนการตรวจทีละยีน |
| ต้นทุนสูง | อาศัยการศึกษาด้านเศรษฐศาสตร์สาธารณสุขและนโยบายสนับสนุน |
| ความเป็นส่วนตัวของข้อมูล | ต้องมีกฎหมายคุ้มครองข้อมูลพันธุกรรมที่ชัดเจน |

## 13.6 บทบาทของ AI และ Machine Learning ต่อเภสัชพันธุศาสตร์

เทคโนโลยีปัญญาประดิษฐ์กำลังเข้ามามีบทบาทมากขึ้นในการพัฒนาเภสัชพันธุศาสตร์ โดยสามารถช่วยได้ในหลายด้าน ดังนี้

- **การทำนายฟีโนไทป์จากจีโนไทป์ที่ซับซ้อน** โดยสามารถทำนายฟีโนไทป์ที่รวมตัวแปรหายาก (Rare variants) ซึ่งยังไม่มีอยู่ในแนวทางของ CPIC
- **การทำนายปฏิกิริยาระหว่างยา-ยา-ยีน** โดยคำนวณฟีโนไทป์ที่แท้จริงเมื่อผู้ป่วยได้รับยาหลายชนิดพร้อมกัน
- **การสร้างโมเดลเฉพาะประชากร** เช่น การสร้างโมเดลที่เหมาะสมกับคนไทยโดยเฉพาะ ซึ่งอาจแตกต่างจากโมเดลที่พัฒนาจากประชากรตะวันตก
- **การสนับสนุนการตัดสินใจทางคลินิกที่ชาญฉลาดขึ้น** โดยสามารถแสดงคำแนะนำที่เหมาะสมให้แพทย์เห็นได้ภายในเวลาเพียงไม่กี่วินาที

## 13.7 ประเด็นจริยธรรมที่ต้องพูดถึง

### ความเป็นส่วนตัวของข้อมูลพันธุกรรม

ข้อมูลยีนของผู้ป่วยแต่ละคนไม่ได้เป็นเพียงข้อมูลส่วนบุคคลเท่านั้น แต่ยังบอกข้อมูลบางส่วนเกี่ยวกับพ่อแม่ พี่น้อง และลูกหลานด้วย ซึ่งนำไปสู่คำถามที่ยังไม่มีคำตอบชัดเจนในบริบทของประเทศไทย เช่น บริษัทประกันสามารถใช้ข้อมูล PGx เพื่อปฏิเสธการทำประกันได้หรือไม่ ใครควรเป็นเจ้าของข้อมูลยีนที่แท้จริง และข้อมูลเหล่านี้ควรถูกเก็บรักษาไว้นานเพียงใด

### ความเท่าเทียมในการเข้าถึง (Health Equity)

ตราบใดที่การตรวจ PGx ยังมีราคาแพงและมีความซับซ้อนสูง ก็มีความเสี่ยงที่จะเกิดความเหลื่อมล้ำขึ้น กล่าวคือผู้ที่มีฐานะดีอาจได้รับยาที่เหมาะสมกับตนเองมากกว่า ในขณะที่ผู้มีรายได้น้อยยังคงต้องใช้ยาแบบมาตรฐานเดียวสำหรับทุกคน แนวทางที่กำลังได้รับการพัฒนาเพื่อแก้ไขปัญหานี้ ได้แก่ การนำ PGx เข้าสู่ระบบประกันสุขภาพ การลดต้นทุนด้วยเทคโนโลยีใหม่ การพัฒนาแนวทางที่เหมาะสมสำหรับประเทศกำลังพัฒนา และการใช้ Point-of-care testing ที่รวดเร็วและมีราคาถูกกว่าการตรวจแบบเดิม

### ยีนไม่ใช่คำตอบสุดท้าย

ประเด็นสำคัญที่ต้องสื่อสารให้ผู้ป่วยเข้าใจอย่างถูกต้องคือ ผลตรวจยีนที่ออกมาเป็น "ปกติ" ไม่ได้หมายความว่าผู้ป่วยจะไม่มีความเสี่ยงใด ๆ เลย เพราะยังมีปัจจัยอื่นที่ส่งผลต่อการตอบสนองต่อยาได้อีกมาก เช่น ปฏิกิริยาระหว่างยากับยา โรคตับหรือโรคไต อายุที่ส่งผลต่อพัฒนาการของเอนไซม์ อาหารและสมุนไพรบางชนิด รวมถึงตัวแปรทางพันธุกรรมที่หายากซึ่งยังไม่เป็นที่รู้จักในปัจจุบัน

ตลอดหนังสือเล่มนี้ ผู้อ่านได้เดินทางผ่านเนื้อหาต่าง ๆ ดังสรุปในตารางที่ 13.5

| บท | เนื้อหาหลัก |
|---|---|
| 1 | DNA, mRNA และโปรตีน รวมถึง SNP ที่เปลี่ยนแปลงทุกอย่าง |
| 2 | ADME: เส้นทางของยาในร่างกาย |
| 3 | Big 5 CYP Enzymes: ผู้พิทักษ์ของตับ |
| 4 | Star Alleles, Diplotype และ Activity Score |
| 5 | Prodrug กับ Active Drug: ยาสำคัญ 4 ชนิด |
| 6 | CPIC: จากวิทยาศาสตร์สู่แนวทางคลินิก |
| 7 | ยาหัวใจ: Clopidogrel, Statins และ Warfarin |
| 8 | ยาจิตเวชและยาแก้ปวด: SSRIs และ Opioids |
| 9 | HLA: ยีนภูมิคุ้มกันและปฏิกิริยาแพ้ยารุนแรง |
| 10 | DDGIs: ปฏิกิริยาสามฝ่ายระหว่างยา ยา และยีน |
| 11 | Transporters: เส้นทางลับในร่างกาย |
| 12 | PGx ในกลุ่มพิเศษ: เด็ก ผู้สูงอายุ และกลุ่มชาติพันธุ์ |
| 13 | อนาคต: ตรวจครั้งเดียว ใช้ได้ตลอดชีวิต |

เภสัชพันธุศาสตร์ไม่ใช่เรื่องของอนาคตอีกต่อไป แต่เป็นเรื่องของวันนี้สำหรับผู้ป่วยโรคหัวใจชาวไทยที่อาจกิน Clopidogrel แล้วไม่ได้รับการปกป้องจากลิ่มเลือดอย่างเพียงพอ สำหรับผู้ป่วยมะเร็งที่กิน Tamoxifen แล้วได้รับ Endoxifen ไม่เพียงพอต่อการรักษา และสำหรับผู้ป่วยทุกคนที่ได้รับยาในขนาดที่ไม่เหมาะสมกับตนเอง หน้าที่ของนักศึกษาและบุคลากรทางการแพทย์ในฐานะผู้ที่จะดูแลระบบสุขภาพต่อไป คือการเรียนรู้ พัฒนา และนำความรู้เหล่านี้ไปใช้สร้างระบบสุขภาพที่ผู้ป่วยทุกคนได้รับยาที่ใช่ สำหรับคนที่ใช่

## คำศัพท์สำคัญ

| ศัพท์ | ความหมายโดยย่อ |
|---|---|
| **Reactive PGx** | การตรวจยีนภายหลังจากเกิดปัญหาจากการใช้ยาแล้ว |
| **Preemptive PGx** | การตรวจยีนล่วงหน้าก่อนเริ่มการรักษา และเก็บผลไว้ใช้ในระยะยาว |
| **EHR (Electronic Health Record)** | ระบบเวชระเบียนอิเล็กทรอนิกส์ที่ใช้เก็บและเรียกดูข้อมูลผู้ป่วย |
| **Multi-gene Panel** | การตรวจยีนหลายตัวพร้อมกันในการทดสอบครั้งเดียว |
| **Alert Fatigue** | ภาวะที่บุคลากรทางการแพทย์เพิกเฉยต่อการแจ้งเตือนเพราะมีมากเกินไป |
| **Health Equity** | ความเท่าเทียมในการเข้าถึงบริการทางการแพทย์ รวมถึงการตรวจ PGx |
| **Point-of-care testing** | การตรวจที่ทำได้รวดเร็วในสถานที่ให้บริการ โดยไม่ต้องส่งตรวจนอกสถานที่ |

## คำถามทบทวน

1. เปรียบเทียบข้อดีและข้อจำกัดระหว่างแนวคิด Reactive PGx และ Preemptive PGx โดยยกตัวอย่างประกอบ
2. หลักฐานจากการศึกษา PREPARE และการศึกษาในสิงคโปร์สนับสนุนแนวคิด Preemptive PGx อย่างไรบ้าง
3. อธิบายว่าเหตุใดการวิเคราะห์ความคุ้มค่าทางเศรษฐศาสตร์สาธารณสุขจึงสนับสนุนการลงทุนตรวจยีนล่วงหน้า แม้จะมีค่าใช้จ่ายเบื้องต้นก็ตาม
4. ยกตัวอย่างความท้าทายในการนำ PGx เข้าสู่ระบบ EHR อย่างน้อย 2 ข้อ พร้อมแนวทางแก้ไข
5. เพราะเหตุใดผลตรวจยีนที่เป็น "ปกติ" จึงไม่ได้รับประกันว่าผู้ป่วยจะไม่มีความเสี่ยงจากการใช้ยาเลย
